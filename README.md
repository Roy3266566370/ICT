# 万象 WANXIANG

把已有 PPT 转为可翻页、可编辑、可调参的交互网页；在课件入口之外，另提供“题目交互实验室”，把 PDF、题目截图、PPTX 或粘贴文字中的一道题编译成可执行、可核对、可保存的学习成果。

## 本地运行

本轮验证环境：Windows、Python 3.11、Node.js 24.13。

```powershell
py -3.11 -m pip install -r backend/requirements.txt
cd frontend
npm install
npm run build:offline
cd ..
powershell -ExecutionPolicy Bypass -File .\start-dev.ps1
```

打开 http://localhost:5173/ 。真实API为默认模式，`VITE_USE_MOCK=true` 才启用手工示例数据。启动脚本保留本地访客会话签名，重启服务后仍可恢复有效材料。

## 使用流程

1. 上传 `.pptx`，等待预览与识别。原页先生成，识别继续在后台进行。
2. 打开生成的网页：左侧缩略图，中央原页，底部翻页；“开始演示”进入全屏。
3. 点击图上的交互入口进入独立“实验”状态：问题、主画布、关键控制、时间轴和当前结论同屏；原稿通过“原稿对照”按左右两栏查看，返回原页不丢参数。“开始演示”进入演示态，只保留实验/原稿与播放控制。页标题行或演示顶栏提供 −、缩放滑杆、百分比、＋、适应，Ctrl/⌘+滚轮可连续缩放，放大后用滚轮/滚动条查看。
4. “编辑内容 / 交互”打开自由编辑：改字、移动、缩放、旋转、样式、表格行列与图表数据即时生效；对象分离后按原 PowerPoint 画布的真实边界放置，不拉伸溢出文字。工具栏缩放控件同样支持连续百分比、±、适应和 Ctrl/⌘+滚轮，放大后画布可滚动。
5. 属性面板分“外观 / 交互”：公式可写 `y = x^2 + 2*x`、勾选可调变量、设置初值/范围/步长并即时看曲线；图形可选用矩阵、圆→椭圆、特征探针、逆映射、面积、换基模板；图表直接绑定当前数据。新建文字和原页对象使用同一套配置。
6. 交互配置写入网页文档，不触发整稿重转。移动/缩放保留交互并跟随热区；修改公式、表格或图表数据会更新关系或进入“待核对”，面板给出原因和“重新提取当前内容 / 撤销内容修改”入口。
7. “撤销/重做”恢复参数操作；“对比条件与结果”可保留当前基线、查看差额并恢复。连续拖动合并为一次撤销，重置也是一次可撤销操作。
8. 参数自动保存并显示“有修改，正在保存 / 已保存到服务端 / 同步失败，本机草稿已保留 / 离线修改”。“立即保存”仍可手动触发。刷新后恢复同一组参数。
9. “重新提取本页交互”按当前网页内容重算，不读旧识别缓存；“按原稿整份重转”作为较慢的次级操作保留。“下载交互网页”与“生成分享网页”读取同一版本的内容和参数。

## 万象工坊：高数自由搭建

入口：`/workshop`，默认展示高等数学分类。七个模板已接好线，并附探究问题、动手步骤、预期观察与可编辑的记录便签：

| 模板 | 可探索内容 |
| --- | --- |
| 函数变换与图像 | 参数 a/b/c、函数形状、滑杆控制观察点 |
| 重要极限 sin(x)/x | 左右趋近、函数值与极限的区别 |
| 左右极限与间断 | 单侧极限、双侧不一致、可去间断与发散 |
| 从割线走向切线 | 步长 h、差商、导数、切线及斜率记录 |
| 黎曼和与定积分 | 左/中/右端点、分割数、数值参考与差值 |
| 定积分不等于几何面积 | 正负抵消、绝对值面积、上下限方向 |
| 泰勒展开与局部近似 | 一至五阶、展开中心、多项式系数及点上误差 |

在画布的「添加对象 → 高数」中可独立添加六类积木：函数源、函数图像、极限观察、导数切线、黎曼积分、泰勒近似。函数源支持 `x`、`a`、`b`、`c`、`pi`、`e` 和常用初等函数，乘法写 `*`，幂写 `^`，三角函数采用弧度。将函数源的输出连到各积木的 `f(x)` 端口；滑杆输出连到 `x₀` 可同步多个观察点。导数与积分的标量输出可接记录仪，泰勒的函数输出可继续接图像、导数或积分。连线检查端口类型，多个对象也能封装成自制积木。

函数、参数、接线与笔记沿用现有自动保存、撤销/重做、发布快照和复制改造流程。发布后修改原作不会改变已发布快照。原有三个力学模板保留在「力学实验」分类。

计算边界：极限只提供数值趋近证据，不证明存在性；导数和泰勒系数通过受限表达式解析树上的截断幂级数自动微分，检查左右分支，保留浮点误差。部分复杂的边界表达式会保守拒绝求导或展开。积分仅支持有限区间，参考为 1024 段复合 Simpson 求积，不是解析真值，也不自动计算反常积分或柯西主值。图像与有限采样不替代解析证明；本模块不调用真实模型。

针对性验证：`frontend/src/canvas/calculus.test.ts`、`backend/tests/test_workshop_calculus.py`；浏览器验收脚本与截图位于 `verify/workshop-calculus-2026-11-12/`。

## 题目交互实验室

入口：`/labs`（导航“题目实验室”）。它与 PPT 课件入口并列，不替换原有上传、编辑、实验和分享流程。

**输入与识别**

- 首批支持 PDF、PNG/JPG/WebP、PPTX、TXT/MD/CSV；可一次上传最多 6 个文件，并分别标为“题目 / 补充数据 / 我的解答 / 参考答案 / 课件”。
- PDF 优先读文字层；含嵌入图片的混合 PDF 会补充本地 OCR，扫描版与截图走本机 RapidOCR。保留文字层、OCR 候选和原稿预览；涉及图片公式时要求对照原稿确认指数、分式、根号与区间，核对窗口内可直接看原图和修正题干。PPTX 读取文字与表格。多页试卷会按题号拆分，并把跨页续写合并回同一题；也可以从题目列表切换。
- 识别结果会显示公式、条件、数据与来源摘录；积分区间缺失、起点不明或图数据不完整时先进入“待核对”，确认后才求解。题目没有可计算数据时会使用明确标注的教学示例，原题文字始终保留。
- 未写上下限的积分按不定积分识别，保留原函数族 `F(x)+C`，可调节 C 查看整体平移；明确写了“定积分”但缺区间时仍须核对。教材中的 `arctan x`、LaTeX 函数名与字体标记会整理为统一的计算表达式；短公式截图先分离“例2求”等标签，同时保留积分号、数字系数和上下限。原图与 OCR 候选仍保留，图片公式确认后再求解。
- 题目优先本地识别与求解。进入工作台后，本地未识别类型、未建立可执行模型或仅得到教学示例的题目，会自动使用已配置的 LLM 理解题意、建立声明式模型并交给现有内核计算，无需点击 AI 按钮。文字、文件上传与多题切换共用这一流程。原题、AI 模型、内核结果及参考解答分别保留；缺失条件或未确认的原图公式继续进入核对，不把 AI 参考答案当作内核已验证结果。
- 自动理解沿用现有 `LLM_*` 配置；模型未配置时保留题目与核对入口并显示原因。同一题干与核对条件在当前面板中只自动尝试一次，失败不循环请求，可显式重试；已有 AI 结果从实验室文档恢复，不重复调用。自动请求会等待当前学习记录同步，并隔离跨实验室的迟到响应。
- “学习助手”的按步骤讲解增强仍由 `LAB_AI_ENABLED=false` 默认关闭控制，只有后端开启且学生当次勾选“使用模型增强”才调用。它与上述自动题意理解分别控制；如需开启助手增强，在 `backend/.env` 增加 `LAB_AI_ENABLED=true` 并重启后端。

**四类题目**

公式识别实测：`verify/integral-recognition-2026-11-09/` 保留用户提供的 `∫ x arctan x dx` 图片、上传/核对/求解/调节 C/刷新恢复的响应与截图；另覆盖反正弦、不完整定积分区间与科学计数法。验收时原图无需手工重输公式，确认后结果为 `(x²+1)atan(x)/2-x/2+C`，并通过求导核对。

- 微积分：定积分（曲线、积分区域、黎曼和、解析值与误差）、导数（切线、割线、差商）、函数与 x 轴所围几何面积、明确区域绕 x 轴的旋转体积，以及已确认分支的隐函数法线。几何面积按零点分段，显式不等式区域只计非空部分；面积和体积等多个小问分别求解与核对。反常积分保留无穷上界，图形截断与完整解析值分开标注。证明类问题只把图形和数值作为核对，不替代证明。
- 二重积分：有限单片区域、多项式被积函数，展示两条区域边界、阴影、可移动切片及二维中点和。样题 `D={y²≤x,x²≤y}`、`(x-y+1)²` 的模型为 `0≤x≤1, x²≤y≤√x`，内核结果 `71/210`。本地建模条件未识别时自动由 AI 提取；AI 提供的积分限通过同一内核后接入主画布，保留原题、来源与笔记，可保存和分享回放。短二重积分图片补走公式 OCR，原图公式未核对时保留核对门槛；不支持的分片区域或非多项式函数保留参考解答，交互坐标范围为 ±10⁶。
- 最优化：一维/二维目标函数、梯度、初始点、学习率、迭代轨迹、停止原因与驻点核对；可证明完整的二维驻点集合包含周期族、极值与鞍点分类，无法证明完整时明确说明。有限箱约束多项式目标比较可行内部点、边界点与顶点；一般约束不自动当作无约束问题求解。
- 数据结构与算法：BFS 的真实队列、已访问集合、父节点、层级与逐行伪代码，以及大根堆/小根堆删除堆顶、末尾替换与逐步下滤。堆的树形图、数组、交换高亮和已删除元素使用同一轨迹；初始堆、删除次数或完整回放超限时先核对。
- 深度学习：小型全连接网络的前向、MSE、反向传播梯度与参数更新；可展开各层查看形状、中间数值和梯度，权重来源会标明“题目提供”或“教学初始化”。

- 操作系统：CPU 调度（FCFS / SJF / SRTF / RR / 优先级，甘特图、就绪队列、周转与等待时间，同一组进程可切换算法对照）、页面置换（FIFO / LRU / OPT，物理块逐次变化、缺页统计与 Belady 异常检查）、磁盘调度（FCFS / SSTF / SCAN / C-SCAN / LOOK / C-LOOK，磁头轨迹与总移动距离，回扫是否计入可切换）、银行家算法（Need / Work 逐轮、安全序列，可附带一次资源请求的试分配与回滚；学生写的安全序列只要合法即判正确）。进程表、访问序列、磁道请求、Allocation/Max/Available 等数据缺失时先进入“待核对”，不编造条件；实现见 `backend/app/labs/opsys.py` 与 `frontend/src/labs/opsys.ts`（两端逐帧镜像），画布 `frontend/src/components/labs/OsCanvas.tsx`，用例 `backend/tests/test_labs_os.py`、`frontend/src/labs/opsys.test.ts`。

未识别的题目保留“暂不支持”，不再默认转为最优化教学示例。修正题目文字时，未改动的旧条件不会覆盖新题干；仍不支持的旋转轴、区域边界或分支不能仅通过填写任意确认文字跳过。

**学习方式与成果**

- 自主探索 / 引导解题 / 完整讲解三种模式；支持播放、暂停、单步、回退、速度、重置，自然语言指令（例如“把学习率调到 0.05”“停在第三次迭代”）和按当前步骤的本地导师讲解。
- 选中公式、条件、轨迹点或网络层可以局部追问；分层提示、尝试检查、上传草稿的数值核对、原稿对照、探索情景与虚线对照均可使用。
- 保存的学习成果包含：原题与来源、识别条件、可操作模型、原题解答、执行轨迹（后端重算并写入 `states.evaluated.trace`）、探索情景、学生笔记/观察/尝试。分享快照可公开只读播放轨迹，不包含会话或文件系统路径。
- 关键实现：`backend/app/labs/`（提取/识别/求解/讲解）、`backend/app/api/routes_labs.py`、`frontend/src/labs/`（类型、表达式、计算、指令、历史）、`frontend/src/pages/LabPage.tsx`、`frontend/src/pages/LabWorkbenchPage.tsx`、`frontend/src/pages/LabSharePage.tsx`。

**真实模型连通性（2026-11-07）**

在一次性临时进程中设置 `LAB_AI_ENABLED=true`，通过真实 `/api/v1/labs/{id}/assistant` 发起了一次最小请求：`provider=maas`、`model=DeepSeek-V4.1-Flash-1017`、`local=false`，约 1.9 秒返回；回答正确引用了第 2 步的 `x=1.08`、`f=3.6864`、`‖∇f‖=3.84`。该请求没有修改 `.env`，也没有改变默认服务；当前页面仍默认使用本地导师。其他真实调用（图片输入、长对话、批量材料）仍需单独验收并自行控制费用。

**边界**

- 扫描版 PDF 与图片的首轮 OCR 可能较慢；PPTX 实验室入口只读文字/表格，不渲染原幻灯片图。
- 一般非线性约束、证明题自动证明、大型神经网络完整数值展开不在首版范围；大型网络只做结构或选定局部解释。
- 上传文件只保留在本次会话的实验室目录；分享链接可撤销。离线单文件 HTML 是演示/调参产物，不是可重新导入的工程备份。

## 本轮核心改进

- 交互示例重构：`/examples` 从旧四类模板卡改为数学 / 计算机 / 办公三块可推演画布——曲面积分（可移动截面、环带微元、第一类与第二类积分公式、累加曲线与散度校验）、Transformer（8 步数据流、真实小矩阵、因果注意力热力图、单步数值与公式推导）、经营沙盘（需求—利润曲线、成本瀑布、敏感性龙卷风、情景对比与决策建议）。旧四类模板保留给上传课件识别使用，不再占据示例入口。
- 主页重构：以“一张静态 PPT → 可亲手探索的实验”为主叙事，首屏居中标题与上传/试玩入口，中部左侧原稿、右侧深色剪切实验实时联动，底部三项价值说明；导航新增上传入口，上传面板改为弹窗，移动端自动堆叠。
- 识别与交互形态扩展：从页面文字/图示识别特征探针、换基坐标、奇异值对比、维度与秩、逆映射、行列式四格，并为每类选择不同模板；这份 24 页课件形成 16 页 / 16 个自动交互对象，其中第6/7/8/9/11/13/14/15/17/18/20/21/22/23页使用专门的逐页场景；在自由编辑中新增公式或图形对象才会继续增加对象数。
- 三态播放器：阅读态保留原稿与交互入口；实验态使用独立 ExperimentStage，不再把大图交互层盖在原页上；演示态隐藏编辑/保存/分享/下载等作者操作。关键控制、过程条和当前结论在 1600×1000 下同屏，左侧页导航可折叠。
- 退出实验保持原页尺寸：原页容器重新挂载时重新绑定 ResizeObserver 并立即测量，修复进入再退出实验后原页缩成 120px 的问题；阅读态、演示态和离线网页均已实测。
- 自由缩放：自由编辑器与展示页共用连续缩放控件，范围 25%–400%（编辑器可缩到 15%），100% 以场景页 960px 原始宽度为基准；支持滑杆、±、适应窗口和 Ctrl/⌘+滚轮。放大后可直接拖动画面平移；编辑器还支持“平移”按钮、按住空格或鼠标中键拖动。阅读态控件放在页标题行、演示态放在顶栏；演示时单击页面或滚动滚轮翻页，拖动则平移。

## 支持范围

优先提取原生文字、组合内元素、表格、图表数据和OMML公式。支持受限标量算术、白名单数学函数、有明确依据的二维矩阵映射，以及枚举筛选的数据图表。图片采用局部OCR；不明确内容保留原稿，允许人工纠正/绑定。

不运行PPT宏，不执行用户或模型生成的任意JavaScript。复杂图片公式、通用三维仿真、任意程序、原稿动画复刻仍不在自动转换范围。首轮图片OCR仍可能较慢。离线打包页图上限64MB，超过或缺失预览时明确报错，不悄悄漏页。

三态实验容器、动态结论、双路径顺序实验和 UI04–UI09 的逐页专门场景均已落地。已知边界：第13页在可对角化时仍以矩阵与公式展示完整特征基，尚未画出与旋转案例同等的三步图形；第17页 2×2 压成直线的案例不能拖动列向量，三维案例用等距投影而非自由相机；第14页默认对角矩阵的第一步 Vᵀ 为单位阵，方向对齐可见但无旋转动画；第20页展示唯一原像/整条原像线/无解，不含多点收敛动画；第23页三种关系是随参数计算并同步展示的对照卡，尚不能直接在图上拖动 P/Q。移动端优先阅读和调参，交互对象可单独放大查看；复杂排版编辑以桌面为主。表格支持增删行列，组合图形仍按整体移动/缩放，尚未提供内部元素编辑、任意箭头绘图和可重新导入的工程备份。**离线交互HTML只用于演示与调参，不是可编辑工程备份**；如需继续编辑，请保留浏览器会话中的材料或后续实现工程导出。
