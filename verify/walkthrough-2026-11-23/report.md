## 换基图矢量化精度与耗时

使用仓库的 900 × 485 像素换基图 `frontend/e2e/fixtures/basis-alternate.png`，通过项目的 `LivingVisionClient` 调用当前配置的 `Qwen/Qwen3-VL-32B-Instruct`。配置指向非本机回环端点，耗时包括客户端调用和服务端响应，实际推理机器与单独的推理用时未验证。 [换基图原件](../../frontend/e2e/fixtures/basis-alternate.png)

人工标注两图的四根坐标轴、四个基向量、两个目标向量、一根可见斜虚线及两处坐标文字，共 13 个对象。线段取两个端点欧氏距离的较大值，轴和虚线允许交换端点。坐标文字须抄对括号内的文字，并定位其中心。每个对象的误差必须严格小于图宽的 3%（27 px）。对应方案目标为至少 12/13 个对象达标，且耗时不超过 25 秒。

| 每种输入各一次 | 可评分对象 | 位置达标 | 可评分误差中位数 / 最大值 | 调用耗时 | 响应和标注 |
| --- | ---: | ---: | ---: | ---: | --- |
| 原图，要求像素坐标与嵌套数组 | 2/13 | 0/13 | 153.74 / 163.17 px | 10.12 秒 | [像素坐标](vision-result.json) |
| 原图，按颜色和几何语义描述对象，使用归一化具名字段 | 13/13 | 1/13 | 47.99 / 102.85 px | 60.00 秒 | [归一化字段](vision-result-normalized.json) |
| 同一归一化 Prompt，给图叠加有刻度的 100 单位网格 | 13/13 | 3/13 | 69.97 / 125.54 px | 59.92 秒 | [带网格输入](basis-grid-input.png) · [带网格响应](vision-result-grid.json) |

首轮返回的轴缺失端点，其余几何对象使用扁平数组，坐标文字均抄对但偏差大。归一化具名字段解决了全部对象的格式问题，仅左图坐标文字达到位置阈值。网格让左图横轴和两个基向量达标，右图仍然全部超差。两次归一化调用并行发起，表中延迟是该次请求实测值，单请求延迟与稳定性仍需单独取样。

后续无标注网格的对照 Prompt 固定为归一化具名字段版本，输入图保持原样，针对每个对象给出颜色、起点、端点及顺序定义。网格版本作为位置辅助实验保留。三组结果均未同时达到精度和耗时目标，当前样本上的视觉坐标仅能作为校对候选。复测命令为 `py -3.12 verify/walkthrough-2026-11-23/vision_probe.py --mode normalized`，切换 `--mode pixel` 或 `--mode grid` 可复跑另外两组。 [Prompt 与评分脚本](vision_probe.py)

## 原版工作台走查

1. 在 `/labs` 进入「高等数学 → 空间与曲线曲面积分 → 曲线与曲面积分」，选择「第一类曲面积分（参数曲面）」。输入 `z^2`、`r(u,v)=(cos(u)cos(v), sin(u)cos(v), sin(v))`、`u∈[0,2π]`、`v∈[-π/2,π/2]`，共手填八个字段。两次点击「预览并确认题目」都返回 HTTP 422，页面提示「曲面积分解析值与独立数值复核不一致」。用相同被积表达式 `sin²(v)|cos(v)|` 和上下限单独复现，SymPy 解析得到 `0`，mpmath 数值复核得到 `4.188790204786391`，后者和手算的 `4π/3` 吻合。 [全单位球预览报错](lab-02-sphere-preview-error.png)
2. 仅把 `v` 下限改为 `0`，以上半球继续。预览返回 HTTP 200，勾选已核对全部条件后方可「确认并计算」，创建返回 HTTP 201。进入 `LabWorkbenchPage` 后，结果为 `2π/3`，独立数值复核为 `2.09439510239`。首屏由结果表和两侧面板占据，3D 曲面和操作区需继续下滚。 [上半球确认](lab-04-hemisphere-review.png) · [计算结果和三栏首屏](lab-05-workbench.png)
3. 点「核对识别条件」会打开遮挡曲面与参数控制的弹窗。关闭后可以切换「完整讲解」「引导解题」「自主探索」。3D 预览支持旋转、缩放和网格操作，执行轨迹只有「空间对象」一项，页面上没有可移动截面或随截面联动的积分累积图。 [核对弹窗](lab-06-review-dialog.png) · [引导解题与 3D 操作区](lab-07-guided-mode.png)
4. 回到 `/labs` 的独立曲面积分示例，同一个页面可对照球面环带、面积元、两类积分公式和累计曲线。把 `h` 从约 `0.20` 移到 `0.99`，离散累积从 `2.087` 增至 `4.160`，球面截线和累计图游标同步变化。 [示例初始状态](lab-03-sphere-showcase.png) · [截面与累计曲线联动](lab-08-showcase-cumulative.png)

## M1–M2 实验室验收

上传、识别、条件修正和实验文档仍从 `routes_labs.py` 进入，文本和图片复用已有提取链路。解题过程保存为 `LabProblem.walkthrough`，与既有画布共用实验文档的归属和修订号。后端 `labs/walkthrough/` 负责适用范围、声明式脚本与验算，前端 `components/labs/walkthrough/` 负责播放，曲面与累积图归入 `components/labs/primitives/`。活页视觉实测调用已有 `living/vision.py`。

| 验收项 | 结果 |
| --- | --- |
| 图片上传至过程页 | 将示例的单位球面 `∬ z² dS` 排版为题图。Chrome 从点击「开始识别并建模」到过程首步可见为 22.55 秒。`POST /walkthrough` 返回 200，刷新仅读取已保存结果。 [题图](sphere-question.png) · [过程首步](lab-09-upload-process.png) |
| 五步与参数联动 | 沿高度切片、面积微元、单环带、累积、答案。拖动橙色截面手柄从 `h=0.20` 到 `h=0.65`，同步改变环带和曲线游标。环带数由 12 增到 96，中点和的绝对误差从 0.029089 降到 0.000455，最终精确值为 `4π/3`。 [累计图](lab-10-cumulative.png) · [最后一步](lab-11-verified-answer.png) |
| 逐项验算与修复 | 自动测试把密度改成 `2πz`，确认模型收到对应字段和差异。模型修正后标为通过，持续不符则保留未通过标记。额外覆盖积分区间内的可约零分母、非实向量场、缓存和并发写入。 |
| 条件核对 | 在结果区展开行内核对，原页面仍可操作。图片推断条件单独标注，逐式验算标记仅针对实际计算。 [行内核对](lab-12-inline-review.png) |
| 无模型降级 | 以单独本地实例关闭文本和视觉模型。手工录入同一单位球题，默认显示「结果」，独立数值复核为 4.18879020479，无过程生成请求。 [无模型结果页](lab-13-no-model-fallback.png) |
