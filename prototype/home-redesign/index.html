§ 01 METHOD / 拆题方法

拆题，
是门手艺。

不是把题目丢给一个黑箱，等一句“答案是”。是把题干、图形和数字逐层摊开，让每一步都有来处。

手工
核对
01 READ

先读题，不急着算。

文字层 / OCR

文字层优先，图片走本地 OCR。指数、分式、根号、积分上下限——凡是可能改变结果的地方，原图与候选一起保留。拿不准，就把问题交还给你。

识别核对 · 原图对照 待确认
∫0+∞ x·e−x dx
上限 +∞ 指数 −x 一次项 x
原图与 OCR 候选都保留

认不出的题，不硬答。没有可执行模型时，保留原题、说明原因，而不是套一个最优化示例。

02 MODEL

把句子，变成可执行的模型。

声明式建模

题干被拆成区域、目标、约束与状态。每一行模型都能追溯到原题里的那一句话；参数不是猜的，来源写在旁边。

region D = { y² ≤ x, x² ≤ y } 题干第 1 句
integrand (x − y + 1)² 题干公式
kernel polynomial · 2D 已建模型
内核结果 71 / 210 ≈ 0.3381
03 PLAY

上手，才算真的看懂。

参数 / 轨迹 / 追问

拖动滑杆、单步播放、在任意一帧停下来追问。最后带走的不是一张答案纸，而是一条能回放、能改写、能分享的思考路径。

TRACE · 迭代回放 学习率 0.05
STEP 004 / 018 ‖∇f‖ = 0.061 停在这里 · 可局部追问

数值与图形只作为证据，不替代证明；能给出的边界，我们写在明面上。

§ 02 SPECIMENS / 题目标本

六张标本，
六种拆法。

不是截图，也不靠编造：每个出现的数字，都能在实验室内核里重新跑一遍。

标本编号 A—01 至 A—06 · 持续更新
A—01 微积分 / 定积分

曲线下不是数字，是一叠薄片。

黎曼和、解析值与误差同屏。把分割数调大，看它一步步走向 1/3。

∫₀¹ x² dx = 1/3 打开实验 ↗
A—02 微积分 / 二重积分

两片边界，围出一个分数。

区域、切片与二维中点同屏，模型里的每个不等号都有出处。

71 / 210 ≈ 0.3381 打开实验 ↗
A—03 最优化 / 梯度

每一步，都看得见为什么落下。

梯度、学习率、轨迹与停止原因；鞍点和极小值分别标记。

(0, 0) · ‖∇f‖ < 1e−3 打开实验 ↗
A—04 数据结构 / BFS

队列不是动画，是真的先进先出。

真实队列、父节点与层级；暂停在任何一步，都能看到伪代码停在哪一行。

A → B → C → D → E → F 打开实验 ↗
A—05 操作系统 / 调度

同一组进程，换一种调度再跑。

甘特图、就绪队列、周转与等待时间逐帧联动，可切换五种算法对照。

5 种调度 · 逐帧对照 打开实验 ↗
A—06 深度学习 / 反向传播

每个梯度，都指回它的那次前向。

展开每一层看形状、中间值与梯度；权重来源标明“题目提供”或“教学初始化”。

3–3–3 · 逐层可查 打开实验 ↗

§ 04 BOUNDARIES / 边界

克制，
也是实验室的一部分。

我们把能做的和不能做的，都写在台面上。比“什么都能做”更重要的，是知道什么时候该停下来。

01

不替证明

图形和数值只能作为核对证据。证明题仍然需要写出证明，我们不把“看起来成立”当作成立。

×
02

不硬答

没建立可执行模型的题，保留原题、标注原因。不编造缺失条件，也不默认塞进一个教学示例。

×
03

不跳过核对

图片里的指数、分式、根号与区间，先对照原稿确认。识别结果和候选都留痕，你点头之后才算数。

×
04

不带走隐私

分享快照只保留轨迹、笔记与模型，不含会话信息和文件系统路径；链接可随时撤销。
