# 定积分应用手动输入验收（2026-11-13）

首批支持：有限区间中连续实函数与x轴之间的平面区域面积、该区域绕x轴的旋转体积；另支持题目明确指定0≤y≤f(x)的不等式区域。复用现有 geometric_area/rotation_volume 内核、公式键盘、题目确认、工作台、保存恢复及区域核对。

条件：
- 必须确认区域定义和完整区间，体积还必须明确旋转轴。曲线与x轴之间的区域允许负函数部分；0≤y≤f(x)在负值处没有纤维，不能混为同一题。
- 坐标固定x/y，函数只接受x；不能隐藏接收另一个变量后按x计算。
- 首批要求原式在整个有限闭区间有实定义且连续；不自动补空点、跨瑕点或反转区间。
- 绕y轴、其他旋转轴、两条非零曲线之间区域、反常积分应用和额外不能消费的边界条件均拒绝，不改写为支持的题。

计算与展示：
- 面积完整核对零点并分段取绝对值，不作有向积分的正负抵消。
- 体积以圆盘截面积πf(x)^2计算；只对已确认区域积分。
- 不等式区域仅取非负纤维，区分无正宽度区域与可能残留的孤立零点；空/零面积区域返回0。
- 展示完整区域、精确上下限、旋转轴、内部零点、有效分段、S/V精确值和过程。图形/分割数近似与解析值分开。
- 修复零函数无法确认全部孤立零点而被拒绝的情况；零函数没有孤立零点，但区域面积与体积均可确定为0。
- 修改区域定义通过核对窗口重算，旧答案不能沿用。

算例：
- f=x、[-1,1]：与轴之间面积1，绕x轴体积2π/3；0≤y≤x区域面积1/2，体积π/3。
- f=-2、[0,2]：与轴之间面积4、体积8π；不等式区域为0。
- sin(x)、[-pi,pi]：面积4、体积π²，不能以有向积分0替代面积。
- x^3-x、[-2,2]：全部内部零点-1、0、1，面积5。
- x²在[0,1/3]面积1/81；sqrt(x)在[0,1]面积2/3。
- 零函数及只有孤立零点的不等式区域验证0结果。
- 1/x跨0、消去分母的原式空点、sqrt负定义域、反转区间、漏轴/错轴及额外半径条件均不静默求解。
