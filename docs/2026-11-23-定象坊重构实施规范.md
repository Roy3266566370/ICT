# 定象坊（Workshop & Canvas）体验与视觉重塑实施规范

> **适用对象**：负责执行「定象坊」前端体验、视觉与交互重构的工程 Agent。  
> **参考原型**：请务必先实读并对照 [prototype/wanxiang-workshop-redesign.html](file:///e:/代码/ICT/prototype/wanxiang-workshop-redesign.html)（核心视觉与双模式交互标准）及 [prototype/workshop-redesign/index.html](file:///e:/代码/ICT/prototype/workshop-redesign/index.html)（连续演化过程与三联副图细节）。

## 一、 战略定位与核心目标

1. **定象坊是整个平台的交互底座与插件母体**：
   - 后续「通文册（PPT/讲义）」与「题目实验室」都将降级收敛，直接复用定象坊产出的 **交互仪器态（`CanvasPanel`）** 作为标准交互插件（支持纯前端确定性运算与离线 HTML 完整导出）。
2. **本次重构解决的 5 个核心痛点**：
   - **主次颠倒**：现状中画布节点流图占据左侧 62% 屏幕，核心观察图形却被挤在右侧 360px 窄栏中；点「展开卡片」还会触发 `createPortal` 把画布卡片掏空。
   - **缺乏“连续变化过程”**：目前大多数模板只有静态参数跳变，缺少时间轴播放、上一帧/上一阶残影对照与过程拆解副图。
   - **顶栏杂乱**：[CanvasPage.tsx](file:///e:/代码/ICT/frontend/src/pages/CanvasPage.tsx) 顶栏堆砌了 20+ 控件，仪器面板配置仍是简陋的原生复选框下拉菜单。
   - **画布操控生硬**：外层存在浏览器原生滚动条，缺少左键拖空白直接平移的无限画布手感。
   - **视觉割裂与目录冗余**：卡片缺少语义分级与现代科学仪器质感；[WorkshopPage.tsx](file:///e:/代码/ICT/frontend/src/pages/WorkshopPage.tsx) 目录卡片堆砌过多操作说明文字。

## 二、 视觉设计规范（Design Tokens）

统一沿用“暖纸与精密墨迹（Warm Paper & Precision Ink）”体系，消除硬编码冷灰与生硬边框：

- **基础纸底与墨迹**：
  - 画布/页面底色：`#F6F4EE`（`--paper-bg`）
  - 卡片底色：`#FFFFFF`（`--paper-card`），次级微底：`#FAF8F5`（`--paper-subtle`）
  - 主文字：`#181D24`（`--ink-900`），次文字：`#5E6878`（`--ink-500`），辅助字：`#8C95A4`（`--ink-400`）
  - 发丝边框：`rgba(24, 29, 36, 0.08)`，强调边框：`rgba(24, 29, 36, 0.14)`
- **四大节点语义色**（用于节点顶部 `4px` 色带、端口着色、标签胶囊与流光连线）：
  - **数据源（Source）**：琥珀珊瑚 `#EA580C` / 浅底 `#FFF7ED`（矩阵源、函数源、滑杆、点云、图片输入）
  - **算子变换（Operator）**：靛蓝紫 `#4F46E5` / 浅底 `#EEF2FF`（泰勒、积分、卷积、线性层、旋转器）
  - **观察视图（View）**：青翠绿 `#0D9488` / 浅底 `#F0FDFA`（图像仪、热力图、能量表、决策边界）
  - **流水线/状态（Pipeline/408）**：深海蓝 `#0284C7`
- **字体与排版**：
  - 所有实时读数、坐标刻度、公式系数必须启用 `font-variant-numeric: tabular-nums` 与等宽字体（`--font-mono`），杜绝数值跳动导致的排版抖动。

## 三、 核心交互与架构改造清单

### 1. 顶栏重构（三段式极简顶栏 + 中央双模式切换器）
**涉及文件**：[CanvasPage.tsx](file:///e:/代码/ICT/frontend/src/pages/CanvasPage.tsx)、[CanvasPage.module.css](file:///e:/代码/ICT/frontend/src/pages/CanvasPage.module.css)

- **左侧**：`← 工坊目录` 返回按钮 + 可编辑作品标题 + 极简绿点同步状态（`已保存 / 同步中`，去掉冗长文字胶囊）。
- **中央**：醒目的胶囊分段切换器 **`[ 🎛️ 交互仪器态 | 🧩 积木编排态 ]`**。
  - 凡是预置了 `doc.panel`（或内置模板）的作品，打开默认进入 **🎛️ 交互仪器态**；空白画布默认进入 **🧩 积木编排态**。
- **右侧**：`撤销 / 重做`（图标按钮）+ `保存到工坊` + `发布 / 嵌入活页` 主按钮；次级操作（导出 JSON、新建、恢复默认）收进 `···` 更多菜单。
- **彻底移除**：顶栏原本一字排开的手写笔、色块、橡皮、清屏、缩放按钮，以及丑陋的 `🎛 仪器面板` 复选框下拉菜单。

### 2. 模式 A：「🎛️ 交互仪器态」（主舞台 + 连续过程 + 控制舱）
**涉及文件**：新建/重构 `frontend/src/canvas/InstrumentStage.tsx`（或重构 [NodeInspector.tsx](file:///e:/代码/ICT/frontend/src/canvas/NodeInspector.tsx) 与 [CanvasBoard.tsx](file:///e:/代码/ICT/frontend/src/canvas/CanvasBoard.tsx) 的工作台分支）

- **整体栅格**：左侧自适应主实验区（`minmax(0, 1fr)`） + 右侧固定宽精密控制舱（`340px ~ 360px`），窄屏自动上下堆叠。
- **左侧主实验区（自上而下，所有子块必须加 `flex-shrink: 0` 防止纵向 Flex 压缩截断！）**：
  1. **探究问题条**：单行展示核心探究问题，右侧提供可折叠的 `步骤与观察 ▾` 抽屉。
  2. **主观察舞台（Stage Card）**：
     - 全宽大尺寸高清渲染 `doc.panel.view_node_ids` 对应的主视图，不挤压进侧边栏。
     - **支持画布内直接操纵**：如在函数/积分/优化主图上直接左右拖动探针 `x₀` 或截面高度，附带自动避让边界的**动态引线读数牌（Callout Box）**。
     - **状态条带 / 历史残影**：主图内提供上一阶/上一帧虚线残影对照，底部可附状态条带（如增减/凹凸区间、误差达标邻域带）。
  3. **动态自然语言结论条**：单行根据当前参数实时生成中文结论（带等宽数值高亮）。
  4. **三联过程拆解副图（Minis Grid）**：主图下方提供 `3 列` 紧凑过程卡片（例如：局部微观放大/当前新增项分解 + 误差/斜率随时间轴收敛曲线 + 紧凑高亮读数表）。
  5. **底部固定连续时间轴播放栏（Timeline Bar）**：
     - 独立固定在主实验区底部（不随内容滚走）：`上一帧 / ▶ 播放(支持空格键) / 下一帧 / 回到开头` + 带进度的连续拖动条（Scrubber）+ 关键节点刻度 + 当前进程读数。
     - 对于离散步进或阶数类实验（如泰勒展开、黎曼和分割、割线步长 `h→0`、梯度下降迭代、408 流水线/缓存步进），统一接入此时间轴实现 **60fps 连续演化观察**。
- **右侧精密控制舱（Control Pod）**：
  - 顶部：目标函数/模型切换与衬线体实时公式卡。
  - 中部：`doc.panel.exposed_params` 外露滑杆组（统一带进度填充轨道 `--fill` 与等宽数值胶囊）+ 典型场景一键预设胶囊。
  - 底部：「我的实验观察」笔记框 + 迷你数据流拓扑链（带 `积木连线 →` 一键切到模式 B）。

### 3. 模式 B：「🧩 积木编排态」（纯净无限画布 + 底部悬浮工具坞）
**涉及文件**：[CanvasBoard.tsx](file:///e:/代码/ICT/frontend/src/canvas/CanvasBoard.tsx)、[canvas.module.css](file:///e:/代码/ICT/frontend/src/canvas/canvas.module.css)、[NodeSchematic.tsx](file:///e:/代码/ICT/frontend/src/canvas/NodeSchematic.tsx)

- **移除 `createPortal` 掏空逻辑**：在积木编排态中，100% 屏幕归画布所有，不再把节点内容掏空传送到右侧栏。
- **无滚动条无限画布手感**：
  - 隐藏 `.viewport` 原生滚动条，改为基于 `translate(panX, panY) scale(zoom)` 的变换；
  - 在默认选择模式下，**左键拖动空白处直接平移画布**（按住 `Shift` 拖空白拉框多选），支持光标锚定缩放。
- **左侧可折叠积木库抽屉（Slide-over Drawer）**：
  - 替代原 `<details>` 下拉弹窗，支持搜索、学科分类筛选、点击或拖拽添加到画布。
- **底部居中磨砂黑悬浮工具坞（Floating Dock）**：
  - 集中收纳：`➕ 积木库`、`✋ 平移/选择`、`✒️ 手写识别/曲线拟合`、`🧹 橡皮/清屏` + `− 100% ＋` 缩放、`适应全图`、`自动整理排版`。
- **节点卡片与连线视觉升级**：
  - 每个节点卡片顶部带 `4px` 语义色带；
  - 卡片右上角直接提供 **`📌 主舞台视图`**（切换是否进入 `panel.view_node_ids`）与 **`👁️ 外露参数`** 快捷钉选按钮，所见即所得配置 `CanvasPanel`；
  - 连线使用底轨 + 流动虚线（`stroke-dashoffset` 动画），端口悬停放大并浮现数据类型标签（如 `function f(x)`、`matrix2`、`tensor2d`）。

### 4. 工坊策展目录页（`/workshop`）瘦身美化
**涉及文件**：[WorkshopPage.tsx](file:///e:/代码/ICT/frontend/src/pages/WorkshopPage.tsx)、[WorkshopPage.module.css](file:///e:/代码/ICT/frontend/src/pages/WorkshopPage.module.css)

- **精简首屏**：移除冗长的说明段落与右侧 `.headNote` 框，保留清晰的标题、学科胶囊筛选条与搜索框。
- **高颜值卡片瘦身**：每张模板卡片只保留 **高清渐变预览区（含左上角学科小徽章）+ 标题 + 一句话核心看点 + 底部单行公式与入口**；彻底移除卡片上密密麻麻的 `recipe` 操作步骤小字（统一移入进入实验后的「步骤与观察」折叠抽屉）。

## 四、 工程约束与分阶段验收标准

### 严守边界（避免回归）
1. **数据契约向后兼容**：严格保持 [frontend/src/canvas/types.ts](file:///e:/代码/ICT/frontend/src/canvas/types.ts) 中 `CanvasDoc`、`CanvasPanel`（`view_node_ids`、`exposed_params`）的字段兼容，确保已有云端作品、本地 `localStorage` 草稿、以及活页嵌入（`embedded` / `visibleNodeIds`）和离线 HTML 导出不受破坏。
2. **纯计算逻辑不动**：不修改 [engine.ts](file:///e:/代码/ICT/frontend/src/canvas/engine.ts) 及各学科纯计算测试文件，确保现有前端 `npm test`（662+ 条用例）和 `npm run typecheck`、`npm run build`（含离线运行时）全绿。
3. **布局防裁切红线**：纵向 Flex 容器内的图表卡片必须设置 `flex-shrink: 0` 与明确的 `aspect-ratio`，在 `1280×720`、`1440×900`、`1920×1080` 及 `390×844` 移动端视口下均不可出现主图下半截被压扁裁切的现象。

### 建议执行顺序
1. **Step 1**：重构 `CanvasPage` 三段式顶栏、双模式切换器、底部悬浮 Dock 与左侧可折叠积木抽屉；移除 `CanvasBoard` 中 `createPortal` 掏空逻辑，改为无滚动条拖拽平移画布 + 节点右上角 `📌/👁️` 快捷钉选。
2. **Step 2**：实现「🎛️ 交互仪器态」统一壳层（探究问题折叠条 + 大舞台主图 + 动态结论 + 三联副图插槽 + 底部连续时间轴播放栏 + 右侧带进度填充的控制舱），优先打通高数（泰勒、导数、积分）、深度学习（CNN/激活/优化器）与 408 流水线的时间轴联动。
3. **Step 3**：升级 `canvas.module.css` 节点色带、流光连线与端口样式，并瘦身美化 `WorkshopPage` 目录页。
4. **Step 4**：执行验证：
   ```powershell
   cd frontend
   npm test
   npm run typecheck
   npm run build
   ```
   并使用浏览器在桌面与窄屏下实测「交互仪器态 ⇄ 积木编排态」双向同步、时间轴播放与画布平移缩放无异常。
