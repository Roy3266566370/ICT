# 多元函数极值与条件极值手动输入（2026-11-13）

已接入“选择题型→输入目标与条件→确认题目→本地内核→候选与过程展示→保存重开→核对修改后重算”。任务为 `multivariable_extrema`，固定二元变量 x,y，operation 为 unconstrained / constrained；字段均为字符串。无约束研究整个实平面；条件极值必须明确填写一个完整等式。任务与维度在已保存题中固定，目标和约束可核对修改，修改后重新求解。

复用安全公式解析、现有 complete_extrema 驻点/Hessian分类、constrained 的约束拆分与加边Hessian判别，以及现有数学键盘、输入确认、保存核对和公式结果组件。专用任务不回退到梯度下降示例或单变量曲线，不引入新依赖。

## 准确性规则

- 首批接受六次以内二元实系数多项式目标、四次以内单个多项式等式约束；不是该范围或精确求解未能确认完整时保留原式并标为未完成。含原始分母或非光滑项的式子不靠约分、乘零等操作补回定义域。
- 无约束分别检查两个偏导同时为零；驻点全集完整性与局部分类分别记录。复用既有分类，同时通过严格多项式求解再次确认候选全集及一致性。不可用有限根列表自动证明全部根已求出；无法完全求根时不输出“没有其他极值”。
- 二阶判别列出 A=f_xx、D=f_xx*f_yy-f_xy²。D<0为鞍点；D>0由A区分极小/极大；退化或符号未确认时保留候选并明确未判定，不能因D=0判无极值。
- 等式约束完整保留两端及原始文本，建立 ∇f=λ∇g、g=0；全部候选代回核对。正则点用加边Hessian分类；乘数正负、约束整体缩放不代替该判别。
- 单独求 g=0、g_x=g_y=0 的奇异约束点，并列入候选。普通乘数条件不适用这些点；奇异集合、候选族或分类尚未完成时不输出完整答案。
- 空乘数候选也要检查实可行点证据；不能把无法确认可行集误报成“无极值”。
- 局部极值始终与全局最值分开，不以候选函数值比较证明全局性。
- 不等式、多约束、附加区域边界、缺失/恒等约束明确拒绝；不删去条件计算。不能完成数学判定时仍可保存、重开并展示已核验事实，不误报缺条件。

## 实际算例

| 题目 | 核验结果 |
| --- | --- |
| f=x²+y² | 原点局部极小 |
| f=−x²−y² | 原点局部极大 |
| f=x²−y² | 原点鞍点 |
| f=x⁴−2x²+y² | (−1,0)、(1,0)局部极小，(0,0)鞍点，三个驻点全部保留 |
| f=x+y | 无驻点，整个实平面无局部极值 |
| f=x⁴+y⁴ | 原点驻点已列出，二阶退化，保留未完成状态而非错误地认定无极值 |
| f=xy，x+y=2 | (1,1)约束局部极大，值1；改为x+y=4后重算为(2,2)、值4 |
| f=x²+y²，x+y=1 | (1/2,1/2)约束局部极小，值1/2 |
| f=x+y，x²+y²=1 | (±√2/2,±√2/2)分别约束局部极大/极小，值±√2 |
| f=x+y，x²+y²=0 | 原点作为奇异约束点保留，普通乘数法不足以分类，不遗漏后报无极值 |
| f=x+y，y²−x³=0 | 尖点(0,0)单独列为奇异候选 |
| f=(x−1/3)²+(y−π)² | 精确驻点(1/3,π)，不转成近似输入 |

还覆盖驻点族、约束常值族、空实可行集、复系数、原式定义域空洞、约束整体变号、不可用根式完全求根及非法额外字段。
