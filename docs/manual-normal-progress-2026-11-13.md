# 手动切线与法线验收（2026-11-13）

输入：曲线方程（如 y=x^2、x^2+y^2=1 或 F(x,y)=0 的左端表达式）、有限横坐标、可选纵坐标。坐标支持分数与 pi。省略纵坐标时仅接受内核能确认的唯一实分支；确认页展示完整研究点，多分支不擅自选根。

实现：
- 复用 implicit_normal 内核、公式键盘、预览确认、核对窗口、工作台、保存恢复。
- 原内核 tangent_tex 误放法线，现分别给出切线与法线方程。
- 使用梯度确定两个方向，F_y=0 为竖直切线，F_x=0 为竖直法线；不做除零运算。
- 检查点在原式实定义域及曲线上，拒绝分母为零、绝对值折点、非有限偏导及梯度同时为零的奇异点。不声称这些奇异点在数学上必然没有切线，仅表示本流程不能确认唯一普通方向。
- 前后端追踪在竖直切线附近改为 x(y)，中断后不跨空缺继续找别的根；画布分别叠加切线与法线。
- 手动题冻结探索点控件；换点、换分支通过核对条件重新计算。

实际题：
- y=x^2，P=(0,0)：水平切线y=0、竖直法线x=0。
- x^2+y^2=1，P=(1,0)：竖直切线x=1、水平法线y=0。
- 圆的上/下分支显式指定坐标；在x=0而未指定y时阻止确认。
- y=x^2在x=1/3，精确法线斜率-3/2；y=sin(x)在pi处保留精确点。
- x=y^2在(0,0)使用x(y)画出两侧局部分支。
- 点不在曲线上、y^2=x^2的原点、y=abs(x)原点及原式消去前的零分母均拒绝。
