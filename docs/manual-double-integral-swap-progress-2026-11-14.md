# 二重积分自动分段换序（2026-11-14）

在已有单片、分片、极坐标和首批反常积分入口上，继续扩展直角坐标换序。无需新增条件字段、依赖或迁移手动输入存档。

## 输入和结果

- 两条边界都是二次及以下多项式时，支持非单调边界、换序后必须分段、同一高度存在多个不相连内层区间的区域。
- 原始分片逐片推导，换序结果统一展平成完整分段列表。换序输出的外层区间可以相同，分别表示不同内层区间；所有段相加才是原积分。
- 手动入口新增四道可修改例题：三角形、抛物线弓形、平移直线带、抛物线下方双区间。选择例题后仍需核对全部原始条件并确认，更换例题会取消旧确认。
- 结果区展示每段新积分限、累次积分公式及本段积分值。原区域阴影和切片继续沿用原题条件；保存重开及改限后重算均保留完整列表。
- 原有可验证的单调代数边界回退保留；根号边界的端点允许导数出现竖直切向，原函数在端点的连续性仍单独核验。

## 区域等价检查

按原边界端点值、抛物线顶点值和边界接触点值划分新外层区间，仅保留原区域投影内的分界。每段枚举一次或二次方程的全部实反函数分支，先排除原区间外的分支，再核验实际边界的实定义、范围及全段次序。

各段中全部根的顺序固定，因此相邻根之间的区域成员关系可用精确代数代表点判定；此处建立在全部根已枚举及分界、次序证明上，不使用浮点抽样替代区域证明。相邻的有效内层区间会合并。

换序前后总面积须精确相等；每段积分分别完成独立数值复核，全部分段之和还须与原积分精确值相等。零被积函数也不能绕过区域核验。

本轮修复了旧换序公式缺少原外层端点截断的问题：例如 `0≤x≤1, 0≤y≤x+1`，不能写成 `0≤y≤2, y-1≤x≤1`，后者错误包含负x区域。正确表示为：

- `0≤y≤1, 0≤x≤1`；
- `1≤y≤2, y-1≤x≤1`。

对缺少新区域核验标记的旧存档，后端求解/计算时重新推导换序；前端不展示其旧换序公式为已核验结果，提示通过核对条件重算。原题与原积分保留。

## 算例

| 原区域及f | 换序结果 | 积分值 |
| --- | --- | --- |
| `0≤x≤1, 0≤y≤x, f=x+2*y` | `0≤y≤1, y≤x≤1` | `2/3` |
| `0≤x≤1, 0≤y≤x*(1-x), f=1` | `0≤y≤1/4, (1-sqrt(1-4*y))/2≤x≤(1+sqrt(1-4*y))/2` | `1/6` |
| `0≤x≤1, 0≤y≤x+1, f=1` | 按y=1分为上文两段 | `3/2` |
| `-1≤x≤1, 0≤y≤x², f=1` | `0≤y≤1`时，分别`-1≤x≤-sqrt(y)`及`sqrt(y)≤x≤1` | `2/3` |
| `-1≤x≤1, x²≤y≤1, f=1` | `0≤y≤1, -sqrt(y)≤x≤sqrt(y)` | `4/3` |
| `0≤x≤1, x²≤y≤x²+(x-1/2)², f=1` | 包含内部接触点，推导5段，不重不漏 | `1/12` |
| `0≤x≤1, 0≤y≤1+x+x²/1000000, f=1` | 两段；排除超过画布范围但不属于原区域的负反函数分支 | `3/2+1/3000000` |
