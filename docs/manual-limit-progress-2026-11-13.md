# 精确求导点与手动极限（2026-11-13）

- 求导点支持有限常数表达式，如 1/3、pi、pi/2。符号求值保存精确点，图形使用数值坐标。
- 手动极限输入函数、变量、趋近点、方向；趋近点支持有限常数及 oo/-oo。无穷远只接受通常极限方向。
- 复用现有手动预览/确认API、极限内核、工作台、过程展示和刷新恢复。
- 有限值、无穷发散、左右不同/振荡不存在与无法判定分别显示；不将不存在误报成缺条件。
- 共用公式键盘支持求导点和趋近点；修改点或方向会使旧确认失效。

- 实题：x^2在1/3处求导=2/3；sin(x)在pi处求导=-1；sin(x)/x在0处极限=1；sin(x)/(x-pi)在pi处极限=-1；无穷远有理式极限=1/2；左右不一致与振荡也有后端用例。
