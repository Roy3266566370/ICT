## 1. 为什么删、删了会失去什么

### 1.1 判断依据（可复核的数据）

- 11-02 诊断：24 页真实课件仅 **7/24 页（29%）** 有交互；36 个参数里 **30 个（83%）是推断值**；模型试 2 页、采纳 0 条。24 页中第 4–22 页每页有 1–4 张位图，图示几乎全是图片。
- 为做出演示效果，后来围绕**这一份指定课件**逐页定制了 16 个专门场景（SVD、条件数、换基等）。单份材料好看，但换材料即失效，不是可泛化能力。
- 底层渲染依赖 Windows + 桌面 PowerPoint COM（`deploy/windows-layer-service`），与申报的 ECS 云部署互斥。
- 11-08《项目改进实施方案》已把产品重点改写为「大学理工课程中的可验证交互学习」，并把 I04 微实验学习单列为「**本轮唯一重点新增功能**」——方向信号其实已经在文档里了，只是主入口还挂着 PPT 转换。

### 1.2 根因：不是识别率不够，是价值主张错位

1. **替代品太强**：用户已有 PPT，翻页/放映/编辑 PowerPoint 原生就能做；为「能调几个参数」付出上传 + 等待 + 逐项确认，收益不抵成本。
2. **KPI 逼系统去猜**：「自动转换率」要求从位图里猜数值；猜对只是还原作者，猜错直接伤信任。天花板由材料分布决定，不由算法决定。
3. **真正稀缺的是可核查**：可复算、可追溯、可提交的学习成果，是静态课件和「AI 直接生成 HTML」都不给的，也是评审最容易记住的差异点。

### 1.3 删掉会失去的（必须诚实登记）

- 已有演示素材（逐页场景截图、24 页课件走查）不能再作为「能力证明」，只能降级为历史样例。
- 申报书 5 项量化指标中，跨页关联精确率/召回率失去对应对象，必须等价改写（见第 10 节）。
- 原页阅读/自由编辑若一并删会削弱成果交付形态，因此**保留离线单文件与只读分享**，只删「整份 PPT 保真」部分。

## 2. 新主功能：可核查实验单（Experiment Sheet）

### 2.1 定义

> 一个实验单 = 一个明确问题 + 一组带来源的条件 + 一个白名单算子 + 一段可回放轨迹 + 一份独立复核报告。

**第一公民是「实验单」，不是「材料」**。PPT/PDF/截图/文字都只是输入源之一，不再有「上传一份课件并整稿转换」这个概念。

### 2.2 唯一主路径（5 步，目标 3 分钟内走完）

1. **提问**：截图 / PDF / 粘贴文字 / 直接选已登记模板（不再要求上传整份 PPT）。
2. **核对**：MaaS 给出候选条件、单位、算子与来源摘录；用户逐项确认或修正。每个值标注产地：原稿 / OCR / 模型推断 / 用户补充 / 教学条件。缺必需条件即阻断，不允许「先跑起来再说」。
3. **执行**：编译为登记算子，确定性求值；支持调参、单步、轨迹、对照、反例。
4. **复核**：第二套独立实现重算，输出通过 / 失败 / 未覆盖；**不接受客户端自报「核验通过」**。
5. **交付**：四段式实验单 → 保存、导出 JSON、生成只读分享或离线单文件 HTML。

### 2.3 四段式实验单（产品差异化所在）

| 段 | 内容 | 价值 |
| --- | --- | --- |
| 预测 | 先锁定一个判断，再看结果 | 把「看演示」变成「做实验」，能测出理解而非点击 |
| 操作 | 2–3 个检查点，服务端重算 + `input_hash` | 过程可回放，不是一张结论图 |
| 验证 | 独立复核 + 残差 / 退化 / 边界说明 | 正面回应 AI 幻觉，评审最在意 |
| 迁移 | 换一个条件的同构问题 | 证明学会，而不是记住答案 |

### 2.4 首版能力边界（只做 2 类算子，做透）

- **线性代数**：矩阵作用、特征方向、换基、行列式与面积。标准例 `A=[[2,1],[1,2]]`，`v=(1,1)→(3,3)`、`v=(1,-1)→(1,-1)`。
- **最优化**：梯度下降轨迹、学习率收敛/发散。标准例 `f(x)=x², x0=2`：`η=0.1→x1=1.6`、`η=1.1→x1=-2.4`、`η=0.5→x1=0`。
- 边界必须覆盖：奇异矩阵、零向量、小数与精度、单位缺失、发散停止原因、无解 / 多解 / 搜索超时。
- **明确不做**：任意题目自动求解、任意公式识别、任意脚本执行、班级/评分/排行榜、三维自由相机、整份 PPT 自动转换、通用自然语言画布控制。

### 2.5 新旧对照

| 维度 | 旧（PPT 转换） | 新（可核查实验单） |
| --- | --- | --- |
| 输入 | 整份 PPT（≤20MB / ≤60 页） | 一个问题 / 一道题 / 一次选模板 |
| 核心动作 | 等待自动转换 | 提问 + 核对 + 亲手验证 |
| AI 角色 | 猜页面里有什么 | 提候选条件、写讲解，不决定真值 |
| 结果 | 网页版 PPT | 可复算、可追溯、可提交的成果 |
| 主 KPI | 覆盖率 / 转换耗时 | 复核通过率 / 复现一致性 / 用户提效 |
| 云依赖 | Windows COM，无法上云 | 纯服务端算子，ECS 可跑 |

## 3. 产品定位与用户

- **主要用户**：大学理工科学生（线性代数、最优化），自学与备考场景。
- **次要用户**：助教/教师做课堂演示与布置实验单；课件创建者核对并发布。
- **不设**：班级后台、协作编辑、账号体系之外的角色权限（20 天内不碰）。
- **价值主张**：「别让 AI 替你算，让 AI 帮你能亲手验」。

## 4. 功能架构（六层，标注复用来源）

| 层 | 模块 | 职责 | 处置 |
| --- | --- | --- | --- |
| 输入 | 题目 / 截图 / PDF / 文字 / 模板入口 | 小粒度输入；读文字层、表格、OCR 裁图 | 改造 `labs/extract.py` + `ppt_ai/source_snapshot.py` |
| 理解 | 候选条件与算子建议 | MaaS 输出受 Schema 约束的候选 JSON | 复用 `ppt_ai/client.py`、`model_calls.py`、`planner.py`，去掉「页/区域」维度 |
| 核对 | 来源与产地标注、人工确认 | 摘录 + 原图裁图 + 三态产地，缺条件阻断 | 复用 `ppt_ai/conditions/`、`matching/`、`evidence.py`，去掉 bbox 依赖 |
| 执行 | 算子注册表 + 确定性求值 | 白名单 `operator_id`，纯函数无副作用 | 复用 `ppt_ai/registry.py`、`templates_kernels.py`、`evaluation.py`、`engines/`、`labs/solvers.py` |
| 复核 | 独立实现重算 | 另一条计算路径复算，产出报告 | 复用 `validators/`（精简）+ `ppt_ai/validation.py` |
| 成果 | 实验单、轨迹、导出、分享 | 四段式状态机、冻结快照、只读投影 | 复用 `ppt_ai/snapshots.py`、`branches.py`、`learning_publish.py`、`offline.py` |
| 平台 | 账号、归属、会话、任务、限流 | 私有数据隔离、幂等、模型预算 | 复用 `accounts/`、`db/`、`api/__init__.py`、`ppt_ai/tasks.py` |

**收口原则**：全系统只有一条求值链、一份条件快照、一个 revision。图、公式、数字、讲解、保存、导出读同一份输入哈希。

## 5. 系统架构（华为云）

```
浏览器（提问 / 核对 / 实验 / 查看复核）
        │ HTTPS
        ▼
ECS：Nginx + React 静态前端 + FastAPI
        ├─ RDS PostgreSQL   用户 / 实验单 / attempt / 快照 / 复核报告
        ├─ DCS Redis        任务队列、短期状态、模型预算计数
        ├─ OBS              原始输入、来源裁图、导出的离线 HTML
        ├─ 持久化任务       理解、编译、复核、导出（幂等 + 重启恢复）
        └─ MaaS             候选条件、分层讲解（不承担数值真值）
CodeArts + Skills：需求拆解、编码、构建、部署的过程证据
```

**与旧架构最本质的差别：整条链路不含 Windows / PowerPoint COM。** 这是「基于华为云」从纸面变成事实的前提，也是本次重构最大的技术收益。

数据流约束：

- 密钥只在后端环境；公开分享与离线包不含会话、密钥、内部路径、模型诊断。
- 读接口无生成副作用；生成、重试、发布一律显式写接口。
- 模型调用预算持久化计数，失败与重试也计入；模型不可用时保留确定性路径并给出可理解的原因。
- 「调用失败」「零候选」「候选被校验拒绝」三者在产物中必须可区分。

## 6. 核心契约：ExperimentSheet v1

```jsonc
{
  "contract_version": "experiment-sheet.1",
  "sheet_id": "sht_01HZX...",
  "definition_id": "lin_alg_eigen_direction",
  "definition_version": 1,
  "question": "哪个向量在 A 作用下不改变方向？",
  "conditions": [
    {
      "id": "a11", "value": 2, "unit": "1",
      "provenance": "native",              // native | ocr | model_inference | user_input | teaching
      "source_excerpt": "A = [[2,1],[1,2]]",
      "source_crop": "obs://.../crop_01.png",
      "confirmed_by": "user", "confirmed_at": "2026-11-20T10:00:00Z"
    }
  ],
  "operator_id": "matrix.transform",      // 必须命中白名单注册表
  "bindings": { "matrix": "A", "vector": "v" },
  "checkpoints": [
    { "step": 1, "inputs_hash": "sha256:...", "server_result": { "Av": [3, 3] } }
  ],
  "independent_check": {
    "status": "passed",                   // passed | failed | not_covered
    "reference_impl": "validators/matrix_v2",
    "checked_at": "2026-11-20T10:00:02Z"
  },
  "learner": {
    "phase": "completed",                 // prediction | exploration | transfer | completed
    "prediction_locked": true,
    "transfer_answer": "...",
    "stale": false
  },
  "revision": 7,
  "created_at": "2026-11-20T09:58:00Z"
}
```

约束：

1. 严格 Schema；**不得**把新字段塞进既有 `ppt-ai.1` / `ppt-learning.1` / `1.0` 旧 iSpec 契约。
2. 每个检查点服务端重算并记 `inputs_hash`；不接受客户端自报通过。
3. 内容或条件变化 → 旧结果标 `stale`，保留历史但阻断按当前内容继续提交。
4. attempt 归属三重校验：账号/会话 + sheet_id + revision；仅凭 ID 不得读取。
5. 解释与迁移文字各 ≤1000 字符；单个 attempt 序列化 ≤64 KiB，超限明确拒绝。
6. 状态转换 `prediction → exploration → transfer → completed`；重新预测须显式重新开始，不覆盖已提交历史。
7. 导出 UTF-8 JSON 为必需项；HTML 学习单为可选便捷格式，必须转义用户文字并剥离私有身份与内部路径。

## 7. AI 与确定性计算的分工（安全带）

| 环节 | AI 可做 | AI 不可做 |
| --- | --- | --- |
| 理解 | 提候选条件、单位、算子建议、生成讲解 | 决定数值真值、伪造原稿摘录 |
| 编译 | 建议绑定 | 绕过算子白名单、生成可执行脚本 |
| 执行 | 不参与 | 参与求值 |
| 复核 | 不参与（独立实现） | 自评「通过」 |
| 讲解 | 自然语言与分层提示 | 把推断说成原稿事实 |

**三道闸门**：Schema 校验 → 算子白名单 → 独立复算。任一不过就给出明确的「待核对 / 不支持 / 失败」，绝不降级成「看起来能点」。这条是产品可信度的底线，也是答辩时最值得讲的设计。

## 11. 风险、常见坑与回滚

- **最大风险是删错核**：`ppt_ai` 名字带 ppt，但它是可核查内核而非转换链路。必须按第 8 节清单逐项确认，**禁止按目录名整块删除**。
- **无版本控制**：见 8.4，未建基线不动删除。
- **申报书已提交且不可改**：改用「叙事层重构」——保留作品名称，把实验单作为核心能力升级，量化指标按第 10 节等价替换并附说明，避免演示与材料冲突。
- **20 天贪多**：只做 2 类算子、1 条主路径、1 种成果形态。Three.js/三维、班级、协作、任意题目求解一律不做。
- **AI 空转**（历史上真实发生过：试 2 页、采纳 0 条、原因被覆盖）：模型候选必须落盘脱敏诊断（HTTP 状态、原始响应、逐条拒收原因）；「调用失败」与「零候选」要可区分；先定预算、单次超时与整任务总耗时上限。
- **云上 COM 残留**：删完后全局检查 `Dispatch('PowerPoint.Application')`、`.pptx` 整稿渲染、1920×1080 页图相关引用；残留一条就上不了 ECS。
- **离线包泄密**：导出前过滤会话、密钥、内部路径、模型诊断；公开投影只含用户明确选择的内容。
- **回滚**：保留 `pre-rebuild` 标签与旧链路归档目录一个迭代周期。
