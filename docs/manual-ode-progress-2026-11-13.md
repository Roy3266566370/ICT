# 常微分方程手动输入验收（2026-11-13）

范围：内核能显式求解并核验的1至3阶常微分方程；自变量x/t、未知函数固定y。用户输入方程及可选条件（每行一条），复用手动确认、工作台、保存恢复和核对窗口。首批不接入组合求值、面积、体积目标；这些条件不能额外夹带后被忽略。

输入与结果：
- 支持y'、y''、y'''记号，并提供插入按钮；初值点/值保留分数、pi等常数。空条件表示求解族，不填默认初值。
- 方程、全部条件、自变量一起确认。初值条件格式错误、重复/矛盾或变量不匹配时不静默丢弃。
- 代回原方程核验残差，逐条核验条件；显示阶数、识别类型、解/解族、核验状态和可确认的实解区间。
- 条件不足时保留任意常数，不声称唯一解，也不任意取常数绘制示例曲线。
- 求解器返回多个分支时不再默认取第一支，保留“未确认分支”的未完成结果。
- 单个已核验的解或解族不等于全部非线性解的完整分类；不宣称覆盖所有奇解、平衡解与分支，也不将代入检验当作唯一性证明。

原式与绘图：
- 原方程中的分母条件单独核查，不因x/x、y/y提前约去就允许在零分母条件点求解。
- 只为已完成核验、无任意常数且有可确认实区间的解绘图；观察窗口围绕条件点，并限制在同一实解分支内，避免跨越发散点。
- 前端缺少核验标志时不默认显示通过；未给条件显示“不适用/未给条件”，不伪称已核验初值。
- 核对窗口支持修改方程、自变量和逐行条件，也允许明确清空初值后重新求解族。

实际算例：
- y'=y，y(0)=1：exp(x)；无初值时保留C1*exp(x)。
- y'+y=x，y(0)=1：x-1+2exp(-x)。
- y'=x*y，y(0)=1：exp(x²/2)。
- y''+y=0，y(0)=0、y'(0)=1：sin(x)。
- y''+2y'+y=0，y(0)=1、y'(0)=0：(x+1)exp(-x)。
- y'''=0，y(0)=1、y'(0)=2、y''(0)=6：1+2x+3x²。
- 分数/pi初值、t自变量、部分条件保留常数、有限时刻发散与原式无定义点均有用例。
