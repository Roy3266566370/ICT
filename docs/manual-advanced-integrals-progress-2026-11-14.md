# 高级积分手动输入（2026-11-14）

题目实验室沿用“输入完整条件 → 预览确认 → 本地内核 → 过程展示 → 保存重开 → 核对修改后重算”。不经过题干识别或AI求解，不新增依赖。

## 入口与范围

- 二重积分的“区域模式”可选直角坐标单片、分片、极坐标、二重反常积分。
- 分片每行填写 `外层下限;外层上限;内层下界;内层上界`，1至20片，所有片共用已选积分次序。外层区间不允许重叠；各片之并为完整区域，不强行补齐中间空隙。逐片保留上下限、求和、阴影与切片。
- 极坐标仍填写原函数 `f(x,y)`；极角填写常数，极径边界允许 `theta`。内核作 `x=r*cos(theta), y=r*sin(theta)` 代换并乘雅可比 `r`。极径非负、上下界按全区间核验，极角跨度不超过 `2*pi`，防止重复覆盖。
- 单片和分片可勾选“自动换序”，由原区域推导新限并独立复核。支持既有内核可验证的单调边界；分片逐片换序，任一片失败时保留原条件与未完成原因，不给出部分换序冒充完整结果。手动切换输入次序仍清空积分限并取消确认。
- 定积分的“积分类型”可选反常积分，支持 `oo/+oo/-oo/inf/+inf/-inf/∞/+∞/-∞` 和有限瑕点区间，数学键盘补充正负无穷。逐个瑕点分别检查两侧，双无穷端分开检查，不以柯西主值抵消发散。
- 二重反常积分首批支持矩形常数边界、可分离乘积。保留原始表达式的实定义域检查；分别证明绝对收敛后计算乘积。不变号且绝对积分发散时输出发散；条件收敛、无法分离、曲边反常区域或无法核验的情况保留完整原题并标记未完成。

## 保存与结果

高级区域仍用扁平字符串条件存储：`region_mode`、`pieces_text`、`theta_lower/theta_upper/radius_lower/radius_upper`、`swap_order`；一元反常积分使用 `integral_mode=improper`。既有单片条件保持兼容，不强制迁移旧文档。

核对窗口支持多行分片字段，编辑函数、分片或积分限后重新构建模型和答案，不沿用旧区域。区域模式、次序和换序要求在核对窗口固定；需要更改时从手动入口重新填写和确认。

普通二重积分对原函数作连续实定义的充分条件检查；极坐标对每个原始子表达式分别代换，在极角与极径参数域上检查，支持排除原点的环域倒数函数。充分条件仍可能保守拒绝部分合法函数。原始边界中被化简掩盖的非实项或零分母不能通过确认。

反常积分不提供有限截断的黎曼和或假零误差；计算面板直接展示内核收敛结论与过程。收敛、发散、未完成分别保存，不误报为缺少原题条件。

## 算例

| 输入 | 结果 |
| --- | --- |
| `x+y`；两片 `0;1;0;x` 与 `1;2;0;2-x` | `4/3` |
| `x^2+y^2`；`0≤theta≤2*pi`，`0≤r≤1` | `pi/2` |
| `1`；`-pi/2≤theta≤pi/2`，`0≤r≤2*cos(theta)` | `pi` |
| `1/(x^2+y^2)`；完整圆环 `1≤r≤2` | `2*pi*log(2)` |
| `x+2*y`；`0≤x≤1`，`0≤y≤x`，要求换序 | `2/3`，换序为 `0≤y≤1`，`y≤x≤1` |
| `exp(-x)`，`0` 到 `oo` | 收敛，`1` |
| `1/(1+x^2)`，`-oo` 到 `oo` | 收敛，`pi` |
| `1/sqrt(x)`，`0` 到 `1` | 收敛，`2` |
| `1/x`，`-1` 到 `1` | 发散，不输出主值 `0` |
| `exp(-x-y)`，第一象限 | 绝对收敛，`1` |
| `1/sqrt(x)/sqrt(y)`，单位正方形 | 绝对收敛，`4` |
| `1/x`，单位正方形 | 发散 |
| `1/(x*y)`，`[-1,1]²` | 不满足绝对收敛充分条件，保留未完成，不输出抵消值 |
| `x-x`，第一象限 | 收敛，`0` |
