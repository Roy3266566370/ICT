# 证明与综合题手动输入（2026-11-14）

已接入“选择证明类型→填写函数/区间/命题或步骤→确认原题→证明内核逐项核验义务→证书或未认证原因→保存重开→核对修改后重新认证”。证明题不参与自动判分。

## 支持范围

| 类别 | 类型 | 输入 | 核验结果 |
| --- | --- | --- | --- |
| 存在性 | 零点存在性（介值定理） | f(x)、[a,b] | 闭区间连续、端点有限、端点异号/为零；给出介值定理证书 |
| 存在性 | 零点存在且唯一 | f(x)、[a,b] | 在零点存在基础上核验开区间严格单调性；给出唯一性证书 |
| 中值定理 | 罗尔定理 | f(x)、[a,b] | 闭区间连续、开区间可导、端点值相等；可给出导函数零点见证 |
| 中值定理 | 拉格朗日中值定理 | f(x)、[a,b] | 连续性、可导性；给出中值斜率 |
| 中值定理 | 柯西中值定理 | f(x)、g(x)、[a,b] | f/g 连续可导、g′保持同号、g(b)-g(a)≠0；给出 f′/g′ 中值证书 |
| 不等式 | 单调性证明 f≥0 | f(x)、[a,b] | 连续性、导数符号与起点/终点非负条件 |
| 不等式 | 两个函数作差 | 左右表达式、关系符号、[a,b] | 对差函数核验单调性与端点条件；关系仅支持 ≥、≤ |
| 反例 | 反例否定全称命题 | 左右表达式、关系、反例点 | 核验反例点有定义且原关系在该点不成立 |
| 综合题 | 局部等式步骤核对 | 命题陈述、1至20行 lhs=rhs | 逐步化简核对代数恒等；明确不认证整体逻辑、不自动判分 |

## 证明状态与语义

- `verified`：模板条件全部通过，给出可复核的定理证书。
- `disproved`：反例代入成立，全称命题被否定。
- `local_steps_verified`：局部等式步骤全部通过，但整体证明逻辑未认证。
- `invalid`：至少一个证明义务或条件不成立，当前证明尝试无效。
- `unverified`：内核不能认证该证明，保留已通过/未通过的义务与原因，不猜测结论。

只有 `verified` 与 `disproved` 记为完整结果；其他状态保存原题条件、义务与原因，结果区显示“未认证/局部步骤”，不输出“已证明”。

## 输入与边界

- 函数与表达式只使用变量 x；区间端点必须是有限实常数且下限小于上限；关系符号按类型严格限制。
- 严格单调性使用“开区间导数严格同号”的充分证书；导数仅在孤立点为零或不能确认符号时保留未认证。
- 柯西中值定理用 g′ 在开区间严格同号证明分母不为零；不能确认时保留未认证。
- 两个函数作差的不等式首批只支持单调差函数证书；例如 `x²≤x` 在 `[0,1]` 上虽然成立，但差函数不单调，内核会保守地返回未认证。
- 反例点必须使左右表达式有定义；该点满足原关系时，内核明确说明“不是反例”。
- 综合题步骤按行保存原文结构，逐行核对等式；某一步不成立时整体证明无效，但不会把局部通过当作完整证明。

## 限制

- 只认证模板条件与对应证书；不提供一般数学命题的自动证明。
- 严格单调性、g′同号、差值单调性均使用保守充分条件；条件不足时保留未认证。
- 综合题仅核对局部等式，不认证证明结构、存在性逻辑或多小问依赖。
- 反例只验证所给点是否使命题不成立，不搜索反例。
- 未修改认证、首页、全局样式与离线资源；未提交推送，未做全项目回归。


## 2026-11-14 修复

- 手动证明保留原式结构，不再用 `simplify` 抹去 `sqrt(x)^2` 等表达式的实定义域；负数区间上的中值定理现在会因连续性义务失败而标为无效。
- 端点零与端点符号改用精确代数判定，不再使用 `1e-12` 数值容差；`10^(-13)` 不会被认证为零点，`-10^(-13)≥0` 不会被认证为不等式。
- 介值定理与唯一零点证书在端点为零时改报 `c∈[a,b]（零点可在端点）`，不再错误写成开区间。
- 反例点增加实定义域核对，定义域外的点不能否定全称命题。
