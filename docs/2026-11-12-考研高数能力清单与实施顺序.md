# 考研高数能力清单与实施顺序

整理日期：2026年11月12日。对象为万象题目实验室，不含线性代数、概率论与数理统计。

结论：应按下列能力族逐步覆盖近十年真题，不能把已有SymPy依赖、一个演示场景或某道样题通过当作整章支持。先修正积分与极值的正确性缺口，再补极限、函数研究、积分区域和多步组合。

## 资料与核验范围

- 题源覆盖2017—2026年数学一、二、三，共30份试卷。已下载三份1987—2026试题重排汇编，定位这30份试卷的物理页；对高数解答题建立146条逐题主题记录。选择、填空按能力族补充代表题；2026三卷高数选择、填空、解答题另有逐题目视核验记录。**不是对近十年所有客观题的逐题人工校勘，也不是对30卷参考答案的全量正确性审计。**

## 状态口径

- **已支持**：该行明确限定的计算子能力已存在；不表示整章、所有参数或Agent端到端识别都通过。须同时阅读边界列。
- **部分支持**：只有子能力，或存在入口、定义域、完整性、复核、交互上的缺口。
- **待补充**：当前没有可直接消费的声明式任务和完整求解链路；底层库可能会算，不等于产品支持。

清单中的已支持重点是“内核”。前端能否可视化、Agent能否稳定提取需要单独验收。只有2025数三19（桌面1.png）在本次会话中有原图理解、内核计算复核、交互调参的完整实测，不能由此推断51项能力的端到端通过率。

## 必须先处理的正确性问题

以下为实际调用compute_plan得到的结果，本次只审计，未修改产品实现：

1. **内部瑕点积分误通过**：integral输入1/x^2，区间[-1,1]，返回-2且检查pass；实际发散。有限端点不能直接保证可用Newton–Leibniz。先按原式定位奇点、拆分后做单侧极限；拒绝把数值失败或采样未命中奇点当通过。
2. **一元极值语义不足**：optimization输入-x^2、goal=extrema、bounds={}，返回x*=0，未明确它是极大值且无全局最小值。应区分驻点、局部分类、最大/最小、全局性和完整性；闭区间还须列并列最优点。
3. **未知完整性不等于求解成功**：2026三卷共同指数型二元极值题返回stationary_complete=false，但迭代检查仍pass。应将原题任务标为未完成，不让迭代正常掩盖缺解。
4. **互动数值与解析答案区分**：浏览器改点后的中心差商不得标“精确斜率”；改区间后的数值参照不得与原题解析值混用。数值实验可以展示，但不能承诺完整证明。
