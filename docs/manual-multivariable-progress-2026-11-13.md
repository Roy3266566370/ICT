# 多元函数微分学手动输入（2026-11-13）

首批范围：显式二元(x,y)与三元(x,y,z)实函数的一阶偏导、全微分、方向导数及梯度。复用安全表达式解析、SymPy符号求导、单变量精确极限、手动确认/核对、保存恢复和公式展示；新增专用任务，避免把梯度问题替换为最优化示例。

输入：
- 明确变量顺序。点坐标与方向分量按顺序完整输入，可使用分数、pi、sqrt等有限实常数，不补0。
- 偏导必须明确所求变量；梯度/全微分/偏导可不填点，给出有充分适用条件的符号表达式。
- 方向导数必须给点、非零方向和正向单侧(h→0+)或双侧(h→0)约定；方向向量显式归一化，区别于速度参数的方向导数倍数。
- 方向条件不能夹带到非方向任务后被忽略；变量、点或方向缺分量及零向量明确拒绝。
- 已保存题的任务和变量顺序固定；可核对修改公式、可选点、偏导变量和方向。切换任务/维度在输入页重新确认。

数学核查：
- 求值前逐项检查原式的实定义，不因约分或乘零补回无定义点。
- 点偏导用固定其他变量的双侧差商核验；梯度必须各偏导均存在。
- 使用实初等函数复合的光滑充分条件，单独标注可微性。偏导存在不能证明全微分存在；充分条件无法确认时不把形式线性项当作已成立全微分，也不宣称函数必不可微。
- 方向导数沿单位方向直接核对定义极限；光滑条件通过时再与梯度内积核对，不能确认可微时不套用梯度公式。
- 符号公式列出开域上的充分适用条件，不声称覆盖全部可微点或奇异点。
- 复用结果组件展示公式、偏导表、充分条件、方向归一化和定义约定；不制造多元曲面、单变量曲线或优化轨迹作为答案。

实际算例：
- x²y+sin(y)的x偏导在(1,pi/2)为pi。
- x²+y²在(1,2)的梯度为(2,4)，全微分为2dx+4dy。
- 同点沿(3,4)与(6,8)归一化后方向导数均为22/5，沿反向为-22/5。
- xy+z²在(1/3,2,pi)的梯度为(2,1/3,2pi)；三元方向也单独覆盖。
- sqrt(abs(xy))在原点两个偏导均为0，但沿(1,1)正向方向导数为sqrt(2)/2；使用定义而非梯度内积。全微分未得到充分确认，不输出“df=0”作为已证结论。
- abs(x)在原点沿正x方向的单侧与双侧约定不同；部分偏导可存在而完整梯度不能直接成立。
