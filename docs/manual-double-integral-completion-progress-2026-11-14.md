# 二重积分专用流程继续补齐（2026-11-14）

本轮在已有单片、分片、有限极坐标和自动分段换序上补齐专用输入流程。沿用扁平字符串条件、原题确认、本地计算、保存重开及核对后重算；不新增依赖。

## 入口与支持范围

| 入口 | 已实现条件与判定 |
| --- | --- |
| 普通单片、分片与换序 | 原代数边界之外，允许可核验的sin/cos/tan、exp/log、反三角函数边界。换序可按完整导数临界点拆分，要求每段单调性、反函数、区域覆盖、面积及积分总和全部可核验。二次边界的完整根枚举算法保留。 |
| 极坐标反常积分 | 原函数f(x,y)，有限极角区间且跨度≤2π，常数非负极径，下限有限、上限可∞。逐个原始子表达式变换核查实定义域，自动乘r，保留原点、无穷端与绝对收敛依据。 |
| 曲边区域反常积分 | 有限外层区间与完整连续曲边；令内层变量=下界+(上界−下界)u，0≤u≤1。核验映射除有限退化切片外一一对应，乘面积因子，不省略原函数瑕点。 |
| 仿射变量代换 | 输入x(u,v)、y(u,v)及完整有限参数域。证明常数行列式非零，乘其绝对值，支持负方向、平移和剪切。 |
| 非线性变量代换 | 支持x仅依赖u，y仅依赖v的分离映射；或y关于v为一次式、系数和偏移依赖u的三角形结构映射。证明方向严格单调与退化集合有限，拒绝有面积的重叠覆盖，乘已核验的Jacobian绝对值。 |
| 质量、质心、转动惯量 | 使用有限单片/分片/极坐标区域和密度ρ。非负性用全局性质、单变量真实投影上的函数值域，或多项式Bernstein系数作充分证明；抽样不能作为证明。质心要求严格正质量。惯量必须指定x轴、y轴或过原点垂直平面的轴。 |
| 联合概率的事件概率 | 完整单片支持区域和相同积分次序的单片事件区域分别输入；要求密度非负、整个支持区域积分精确为1、事件全区间包含在支持区域内。越界不自动截断，未归一化密度不偷偷归一化。 |

变量代换统一输入原函数f(x,y)与u/v参数域，绘制的是映射后的原坐标区域，不把u/v图形冒充x/y图形。轮廓取样仅作示意；映射可逆性、面积因子和连续性使用符号依据。

反常积分优先使用分离形式的绝对收敛证明；对不变号函数可使用Tonelli定理及已核验的累次积分，并作独立数值复核。有限参数域中的连续延拓可作为绝对可积的充分条件。无法确认时保留未完成；不取柯西主值抵消，不显示有限截断黎曼和或假零误差。

三角边界的不等式使用实际完整区间上的函数值域核验，避免只得到一个周期的不等式解集后误放行其他周期。周期跨度和符号分段数量设有明确上限；原始函数中被化简掩盖的非实子式、分母和定义域缺口仍单独检查。

## 过程与结果

- 代换展示原区域、坐标映射、Jacobian绝对值、参数域积分及原坐标轮廓。
- 质心分别列出M、∫xρ、∫yρ及正质量归一化；不把∬ρ等号接到坐标向量。
- 惯量明确列指定轴与实际平方距离权重；概率单独列支持区域归一化和事件积分。
- 专用结果使用`double_extension`保存多值与依据；不回退为默认单变量图或原密度的黎曼和。参数域、映射、密度、轴及事件修改均取消旧确认并重算。

## 算例

| 输入 | 结果 |
| --- | --- |
| 全平面exp(−x²−y²)，极径0至∞ | π |
| 单位圆内1/√(x²+y²) | 2π，绝对收敛 |
| 单位圆内1/(x²+y²) | 发散 |
| 0≤x≤1，0≤y≤x，f=1/(x+y) | log(2) |
| 0≤x,y≤1，f=1/(x+y) | 2log(2)，不变号Tonelli依据 |
| 同一区域f=−1/(x+y) | −2log(2)，不取绝对值作为答案 |
| x=2u+v，y=u−v，单位参数方形，f=1 | |J|=3，积分3 |
| x=u²，y=v，单位参数方形，f=x+y | |J|=2u，积分1 |
| x=u²，y=v，0≤u≤1，0≤v≤u，f=1 | 2/3，原坐标区域0≤y≤√x |
| 单位方形ρ=1，质心 | (1/2,1/2) |
| 单位方形ρ=1，关于原点垂直轴的惯量 | 2/3 |
| 0≤x≤1，0≤y≤x，ρ=2；事件x≤1/2 | 支持归一化1，P(E)=1/4 |
| 1≤x≤e，0≤y≤1，ρ=log(x) | 非负性按真实投影核验，质量1 |
| 0≤x≤π，0≤y≤sin(x)，ρ=1，自动换序 | 按x=π/2的临界点生成两段，面积2 |
| 0≤x≤1，0≤y≤exp(x)，自动换序 | 正确保留y≤1时的完整切片，积分e−1 |

额外覆盖：原式复数中间式或正测度实定义域缺口不能通过化简补回；发散的变号全平面奇函数不能通过对称抵消得到0；绝对收敛的奇函数积分保留精确0；非线性平方映射跨越正负u时不忽略双重覆盖。
