## 一、 整体定位与信息架构：为什么放在万象工坊

### 1.1 平台模块分工
* **题目实验室（`/labs`）**：聚焦于有明确标准答案或确定性步骤的求解与核对；深度学习不再勉强扩充传统刷题型计算题，仅保留基础的矩阵维度检查或单步概念核对。
* **万象工坊（`/workshop` + `/canvas`）**：作为深度学习原理展示与自由实验的主阵地。每个实验都是标准的 `CanvasDoc`（节点 + 连线 + 仪器面板），天然复用工坊现有的保存、撤销/重做、公开画廊、Fork 改造与嵌入活页能力。
* **万象活页（`/living`）**：作为叙事与课程编排中枢，以「仪器面板（`panel`）」精简态嵌入工坊中的深度学习实验，配合**活变量**、**先猜再看（`quiz`）**与**门控（`locked_until`）**构成互动式深度学习教材。
* **交互示例（`/examples`）**：保留现有的 [TransformerLab.tsx](file:///E:/代码/ICT/frontend/src/components/showcase/TransformerLab.tsx) 等旗舰级精装展示页面作为门面引导，并增加跳转入口将访客引导至万象工坊对应的专题模板动手拆解。

### 1.2 万象工坊的三级组织结构（科目 → 专题 → 模板）
对照当前 [WorkshopPage.tsx](file:///E:/代码/ICT/frontend/src/pages/WorkshopPage.tsx) 已有分类筛选器，将模板浏览升级为清晰的三级架构：

## 二、 算法谱系全覆盖：6 大篇章与核心实验矩阵

### 2.1 专题 01 · 神经单元与训练动力学（入门必看）
1. **线性分类与 SVM 最大间隔**（衔接线性代数超平面与工作区已有 SVM 教学素材）
   * 直觉目标：理解为什么支持向量只由边界少数样本决定，以及核技巧将低维非线性点映射到高维空间后变线性可分。
2. **激活函数与 10 层梯度连乘探针**（升级复用 `evaluateActivation` 思路）
   * 直觉目标：同屏切换 ReLU / LeakyReLU / Sigmoid / Tanh / GELU，观察单个函数曲线与导数的同时，实时展示**连续乘 10 层导数后的梯度衰减柱状图**，直观演示梯度消失（Vanishing Gradient）与死神经元（Dead ReLU）。
3. **4 种优化器 2D 地形赛跑（Optimizer Arena）**
   * 直觉目标：在同一张 2D 等高线地形（碗状、鞍点、狭长山谷）上点击放置统一起点，同步释放 **SGD、Momentum、RMSProp、Adam**，对比震荡幅度、鞍点逃逸与收敛步数。
4. **过拟合、正则化与 Batch 噪声实验室**
   * 直觉目标：在带噪点 2D 点云上调节 L1/L2 正则系数 $\lambda$、Dropout 概率与 Batch Size，同步观察决策边界平滑度、“训练 Loss vs 验证 Loss 分叉曲线”以及小 Batch 噪声对收敛路径的影响。

### 2.2 专题 02 · 经典深度网络架构（空间变换与梯度高速路）
5. **MLP 流形折叠观察台**
   * 直觉目标：不仅看分类边界，而是将二维正交坐标网格一并喂入前向传播，提供“层级穿梭器（Input → Layer 1 → Layer 2 → Output）”，直观演示线性层 $Wx+b$ 对空间的旋转拉伸以及激活函数对空间的折叠，让双螺旋/异或点云变成线性可分。
6. **CNN 卷积核与感受野透视仪**
   * 直觉目标：左侧 `12×12` 手绘/预设灰度像素画板 + 中间 `3×3` 卷积核（边缘/锐化/模糊/可改权重）、Stride/Padding/MaxPool 开关 + 右侧 Feature Map。点击输出像素可反溯高亮左侧对应感受野与具体乘加式；叠两层 `3×3` 时可逐级高亮穿透至原图 `5×5` 区域。
7. **ResNet 残差跳跃与归一化（BN / LN）对比台**
   * 直觉目标：提供“纯堆叠深层” vs “带 $x + F(x)$ 残差旁路 + Normalization”双路对照，展示每一层激活值方差直方图与反向梯度模长，说明残差结构如何保住深层梯度通路。

### 2.3 专题 03 · 注意力与大模型机制（序列与推理）
8. **RNN / LSTM 遗忘门 vs 注意力直连对比**
   * 直觉目标：演示长序列中普通 RNN 隐状态随步数指数衰减导致的“开头信息遗忘”，对比门控记忆单元与 Attention 的 $O(1)$ 跨距直连。
9. **Scaled Dot-Product Attention A/B 对照沙盘**（升级现有 `attentionSim`）
   * 直觉目标：增加维度滑杆 $d_k \in [2, 64]$ 与“是否除以 $\sqrt{d_k}$”开关，对照大 $d_k$ 时未缩放点积导致的 Softmax 饱和与梯度归零现象；支持矩阵热力图与词元弧线权重图联动。
10. **Multi-Head 多头注意力与位置编码（Sinusoidal vs RoPE）**
    * 直觉目标：展示多头各自聚焦的语义依赖热力图，以及正弦位置编码纹波和旋转位置编码（RoPE）下相对距离对内积的影响。
11. **大模型推理机制：KV Cache 与采样策略台**
    * 直觉目标：左右分屏动画演示自回归逐词生成时“无 KV Cache（重复标红重算 $O(n^2)$ 阶梯增长）”与“有 KV Cache（历史 K/V 灰化锁存）”的算力对比；下方配 Top-10 候选词概率柱状图，拖动 `Temperature`、`Top-k`、`Top-p` 观察截断阈值与概率重分布。

### 2.4 专题 04 · 生成模型与深度强化学习（前沿拓展）
12. **Autoencoder 流形压缩与对比学习（InfoNCE）**
    * 直觉目标：展示高维输入如何压入 2D 潜空间坐标，以及对比学习中正样本对彼此拉近、负样本相互推远的向量力场直觉。
13. **Diffusion 扩散模型双向加噪/去噪向量场**
    * 直觉目标：用 2D 双峰/瑞士卷点云配合时间轴 $t = 0 \leftrightarrow T$，右拉观察逐步加高斯噪声退化成纯噪声；单步反向去噪时叠加 Score 方向箭头场，演示噪声预测网络如何将点拉回高密度流形。
14. **Q-Learning / 策略梯度 2D 迷宫沙盘**
    * 直觉目标：在 `6×6` 网格世界（含奖励终点与陷阱悬崖）中调节折扣因子 $\gamma$、探索率 $\varepsilon$、学习率 $\alpha$，实时更新各格 Q 值热力箭头图与试错步数收敛曲线。

## 三、 万象工坊底层扩展设计：端口协议与原子积木

为保持工坊轻量化，全部运算在浏览器端基于小尺寸二维张量确定性运行，不依赖后端 GPU。

### 3.1 端口类型扩展（基于 `canvas/types.ts`）
在现有的 `PortValue`（`function | matrix2 | scalar | body`）上仅新增 **2 种端口类型**：
1. **`tensor2d`**：受限二维矩阵（维度硬上限如 $\le 16 \times 16$），用于传递小批量输入、权重、Feature Map、注意力矩阵与局部激活/梯度快照。
2. **`dataset2d`**：二维玩具点云数据集（`60~120` 个 `(x₁, x₂, label)` 样本点，含训练/验证集划分标志），专供分类、拟合、正则化与扩散实验使用。

### 3.2 原子积木分类清单
* **数据源积木（输出端）**：
  * `dataset2dSource`（异或 / 双月亮 / 同心圆 / 双螺旋 / 噪声强度滑杆）
  * `pixelGridSource`（`12×12` 可涂抹灰度像素矩阵 + 预设图案）
  * `tokenSeqSource`（4~6 个词的迷你词序列，输出嵌入矩阵）
* **算子积木（输入 → 输出）**：
  * `linearOp`（$Wx+b$，支持正交/Xavier 初始化与权重热力显示）
  * `activationOp`（ReLU / LeakyReLU / Sigmoid / Tanh / GELU，附带局部导数统计）
  * `residualJoin`（双输入相加 `x + F(x)`，方便一键断路对比）
  * `normOp`（None / BatchNorm / LayerNorm 方差分布对比）
  * `conv2dOp`（`3×3` 可编辑卷积核 + Stride / Padding / Pooling）
  * `attentionOp`（缩放点积注意力，$1/\sqrt{d_k}$ 开关 / 温度 $T$ / 因果掩码）
* **训练器积木（动画循环驱动）**：
  * `mlpTrainer`（连接 `dataset2d` 与层配置，借由 `CanvasBoard` 现有的 `live` 动画通道每帧推进 Epoch，输出边界场、Loss 与各层梯度模长，不污染撤销栈）
  * `optimizerArena`（在选定 2D 损失曲面上同步推进 4 种优化器轨迹）
* **观测视图积木（消费端）**：
  * `boundaryView`（2D 决策边界 & 隐层网格流形折叠动画）
  * `matrixHeatmapView`（矩阵热力图，鼠标悬停输出格子高亮对应的输入行与权重列乘加溯源）
  * `gradFlowMeter`（逐层梯度幅值柱状图，梯度 $< 10^{-4}$ 标红预警消失，$> 10$ 预警爆炸）
  * 复用现有 `spark` 记录仪绘制训练/验证双线 Loss 曲线。

## 四、 与万象活页的协同机制（完整教学闭环）

1. **仪器面板（`panel`）作为标准讲义插槽**
   * 工坊中的深度学习模板默认配置 `panel`（勾选主观察视图 `view_node_ids` 与 2~4 个教学核心参数 `exposed_params` 及其安全量程）。
   * 嵌入万象活页后，讲义读者默认进入纯净的“仪器模式”，聚焦观察核心现象；好奇的学生可随时点「克隆到工坊编辑」打开完整积木连线界面拆解或魔改网络。
2. **活变量 + 门控 + 判分联动**
   * 在活页顶部定义页面变量（如 `dk`、学习率 `eta`、正则化系数 `lambda`），正文通过 `[v:eta]` 与 `${expr: ...}` / `${cond ? a : b}` 实时解释当前参数下的动力学状态，同时通过 `bindings` 单向驱动嵌入的工坊仪器块；
   * 关键结论前设置 `quiz`（先猜再看）+ `locked_until` 门控（例如“先预测 Sigmoid 堆叠 6 层后第一层的梯度量级，再解锁下方的梯度分布沙盘”），形成先猜后验的探究闭环。

## 五、 工程边界与分期推进建议

### 5.1 性能与代码边界控制
* **计算尺寸红线**：隐层宽度 $\le 8$、2D 点云样本数 $\le 120$、像素网格 $\le 16\times 16$、序列长度 $\le 8$，保证浏览器单次前向+反向计算耗时 $< 2\text{ms}$，连续训练动画稳定在 60fps。
* **纯函数计算解耦**：将张量运算、反向传播与优化器步进抽离为纯 TypeScript 模块（不依赖 React），支持用 `node --test` 通过数值有限差分自动校验手写梯度实现的正确性。
* **动静分离**：高频训练帧与轨迹坐标仅走 `CanvasBoard` 的 `live` 运行时通道，不触发文档自动保存与历史栈膨胀。

### 5.2 建议落地节奏
* **第一批（快出彩、复用现有资产）**：激活函数与 10 层梯度衰减、优化器 2D 地形赛跑、Transformer `1/√d_k` A/B 对照与 KV Cache 动画。
* **第二批（打通工坊搭积木体系）**：落地 `tensor2d` / `dataset2d` 端口、MLP 流形折叠观察台、CNN `12×12` 像素透视仪，并在 `/workshop` 上线「深度学习」科目与专题分组。
* **第三批（补齐前沿与标杆课程）**：Diffusion 双向向量场、Q-Learning 迷宫沙盘，并在万象活页中配套上线 3~4 篇官方互动活教材。
