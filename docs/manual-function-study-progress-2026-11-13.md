# 函数区间研究手动输入（2026-11-13）

范围：显式单变量实函数、有限精确上下限，可选择闭区间、开区间及两种半开区间。复用现有 function_study 内核入口、公式键盘、确认/核对、保存恢复和函数画布；有限手动区间增加完整性校验与边界取到性分析。

完善内容：
- 用保留结构的原式确认实定义域，与用户区间求交，保留被化简消去的空点。
- 完整求解一、二阶导数零点；补入导数定义域边界与绝对值分支切换点，不能只枚举驻点。
- 在每个已确认光滑且无遗漏零点的区间符号判号；无法完整求根、确认导数定义域或判号时标记未完成。
- 极值要求一阶导数变号；拐点要求函数在该点连续且凹凸方向改变，二阶导数等于零本身不够。
- 原区间端点、实际定义域端点、内部候选点和常值区间分别核对；开端点及缺口只贡献单侧极限，区分最值、无界和未取到的上下确界。
- 结果分别展示定义域、单调性、极值、最值、凹凸性、拐点、端点与候选点。
- 曲线采样跨原式定义域分段时插入断点，避免把1/x跨0点连成一条线。
- 修改区间开闭后必须重新确认；核对窗口可重新计算取到性。

实际算例：x^3-3*x、x^3、x^2、abs(x)、sqrt(x)、1/x、sin(x)在[0,pi]、常函数、x*abs(x)，以及原式有可消去分母的函数。另覆盖非法区间、空实定义域和不能完整求解的临界点集合。

边界：本入口不分析无穷区间或全局渐近线；周期/复杂临界点只在能完整求解时给结论。常值区间不枚举全部非严格极值点，最值取到点可能列出代表点。图形与采样用于观察，不替代完整性检查。

验证：后端联合149项通过；之后补充端点/空点/图形与单调分段检查，专项22项通过；针对分析内核与结构化模型89项通过（与上述部分重叠）。前端421项通过、类型检查通过。浏览器原有流程与新区间研究联合29项通过；修复原式提前化简后，新区间研究6项复验通过，含端点开闭修改与删除峰值点。未做全项目回归；未提交推送。现有登录、注册、Space样式及prototype目录未编辑。

失败案例修复：-x^2*(x/x)曾在建模时提前化简而丢失x=0空点，现从原式保留定义域，在[-1,1]上输出上确界0未取到而非最大值。合并同向单调分段时仅跨越原式连续且有定义的候选点，不跨越空点。
