# 二重积分手动输入（2026-11-13）

已接入“选择二重积分→输入被积函数→选择直角坐标积分次序→完整填写四个积分限→确认原题→本地内核→区域与计算过程→保存重开→核对修改后重算”。保留文件识别与可修改示例。

## 输入与区域

- 先y后x：a≤x≤b，φ₁(x)≤y≤φ₂(x)，先计算内层dy，再计算外层dx。
- 先x后y：a≤y≤b，ψ₁(y)≤x≤ψ₂(y)，先计算内层dx，再计算外层dy。
- 外层上下限必须是有限实常数且下限小于上限；内层边界只能含外层变量，允许两条非零曲线。四个限都必填，不默认从0开始，不自动对调上下限。
- 整个外层区间上检查边界连续实定义与上下顺序，不只检查端点/中点。交叉、反序、原始零分母或非实子表达式明确阻止确认；化简不能补回原式定义域。孤立端点切片退化可保留；上下边界处处相同时明确提示零面积。
- 切换次序会清空四个积分限并取消确认，要求重新按原区域定限，不宣称自动推导等价换序。已保存题在核对窗口固定次序，可改被积函数与四个限并重算；换次序从手动输入页重新填写。
- 单片表示不能容纳的额外约束、分片、极坐标、反常积分不可省略后计算；后续应使用对应专用输入。

## 核验与复用

六个扁平字符串字段 `integrand / outer_variable / outer_lower / outer_upper / inner_lower / inner_upper` 映射到现有 `double_integral` 内核的 `integrand / outer_variable / outer_bounds[] / inner_bounds[]`。原始字段另存，既有数值切片及参数不冒充原题条件。

复用 `_validate_strip` 的边界全区间检查、`compile_model` 的符号累次积分和独立数值复核、`solve_double_integral` 的过程、`evaluateDoubleIntegral` 与 `DoubleIntegralCanvas` 的同区域阴影和切片、以及共享数学键盘/确认/Review/保存组件。内核直接输出内层结果和精确值的LaTeX，避免用用户输入解析器重新解析erfi等合法的内核特殊函数结果。不新增依赖。

手动流程增加原被积函数的连续实定义充分条件检查：对包含D的投影矩形，逐个检查原始子表达式。一元子表达式用精确实定义域及函数值域检查，二元组合按已确认连续的加乘、适用幂和常见连续函数闭合。抽样复核不能替代该检查。这个方法保守；不能确认充分条件不表示积分数学上不存在，也不能误报为用户漏填条件。

无法确认全域条件、无法得到有限精确值或复核失败时，保存完整区域、原始被积函数和未完成原因；不输出数值参考作为答案，不绘制替代示例，不出现默认“黎曼和0、误差0”。零值按精确结果处理，不因字符串/数值为0而拒绝。

## 实际算例

| 题目 | 核验结果 |
| --- | --- |
| f=x+y，0≤x≤1，0≤y≤x | 1/2 |
| f=x+2y，同一区域分别按dy dx和dx dy输入 | 两种次序均为2/3；用非对称被积函数检验变量映射，避免对称算例掩盖坐标互换 |
| f=x+y，0≤x≤2，x≤y≤2x | 20/3，完整保留非零下边界 |
| f=1，0≤x≤1，x²≤y≤√x | 1/3，曲边区域 |
| f=1，1/3≤x≤π，0≤y≤1 | π−1/3，保留精确端点 |
| f=x−y，单位正方形 | 0，保留有符号积分，不误改成几何面积 |
| f=1，0≤x≤1，x≤y≤x | 0，并提示零面积 |
| f=exp(x²)，单位正方形 | √π erfi(1)/2，内核特殊函数结果正常显示 |
| f=x+y，原区域0≤x≤1、0≤y≤x后修改为x²≤y≤x | 由1/2重算为3/20，不能沿用旧区域与答案；核对时保留x、y二元变量列表 |

另覆盖sqrt(x)、log(x)在合法区域、exp(x+y)、exp(xy)、缺限、内层变量自依赖、外层依赖其他变量、小子区间交叉、化简掩盖无定义原式、复中间表达式和内核失败保留条件。
