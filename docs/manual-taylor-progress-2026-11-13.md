# 手动泰勒展开验收（2026-11-13）

输入：显式单变量实函数、必填精确展开点、1至10阶。展开点支持分数、pi、pi/2等有限常数；不填点或阶数越界不能确认。复用手动预览确认、现有泰勒内核入口、公式键盘、工作台、保存恢复与核对修改。

正确性完善：
- 建模和默认图形计算均保留精确展开点；改动数值参数后的实验与已确认原题结果分开。
- 原式在展开点必须实际有定义且具有双侧实邻域，不将可去空点自动补定义，也不把单侧展开冒充普通双侧泰勒展开。
- 逐阶核对双侧普通导数，显示精确 c_k=f^(k)(a)/k!（从k=0开始，零系数保留）。
- 不再统一写O((x-a)^(n+1))。先核验残差比值；可确认下一阶有界时给大O，只能确认Peano阶时给小o，多项式恒等时标记余项为零。余项无法核验时不展示为已完成答案。
- 图形范围取展开点所在实定义域分支内部的局部闭区间，不跨log或有理函数的定义域边界。此区间是观察范围，不是泰勒级数收敛域或默认保证精度的范围。
- 仅在窗口内各阶导数连续且能符号求得n+1阶导数界时，由拉格朗日余项给出窗口误差上界；无法证明时明确无整段误差保证。
- 图中的误差为样本误差，不将样本最大值当作全区间误差上界。逐阶播放也限制在同一观察窗口。

实际算例：
- exp(x)在0处3阶，系数1、1、1/2、1/6。
- sin(x)在pi处3阶，系数0、-1、0、1/6。
- x^2在1/3处2阶，系数1/9、2/3、1，余项为零。
- log(x)在1处展开，观察窗口不越过0。
- sin(t)在pi/2处2阶，保留变量t和精确点。
- abs(x)^(5/2)在0处2阶只能写小o(x^2)，不能强写大O(x^3)。
- sin(x)/x在0未定义、log/sqrt在边界、abs在折点、含可消去空点的原式均不会被自动补成可展开函数。
