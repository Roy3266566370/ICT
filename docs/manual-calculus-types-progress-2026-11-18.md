# 高数题型补齐进度：旋转轴、两条曲线、变限积分与已暴露内核

- 日期：2026-11-18
- 范围：题目实验室 · 高等数学手动输入
- 目标：把“题型缺项”先补成可计算、可核验、可展示的闭环，同时保留一份完整题型地图，未做的不冒充已支持。

## 1. 本次新增或补齐的题型

| 题型 | 入口 | 支持内容 | 关键边界 |
|---|---|---|---|
| 旋转体积（绕 y 轴） | 积分与面积体积 → 旋转体积 | 壳层法 `V=2π∫|x|·高度 dx`，支持曲线与 x 轴、`0≤y≤f(x)` 区域 | 区域必须完整位于 y 轴一侧；跨 y 轴时折叠后不能直接累加，明确拒绝 |
| 两条曲线之间的面积 | 积分与面积体积 → 平面区域面积 | 上边界 `f(x)`、下边界 `g(x)`，按全部交点分段，`S=∫|f-g|dx` | 需能证明交点集合完整；上下边界均须在闭区间连续 |
| 两条曲线之间的旋转体积 | 积分与面积体积 → 旋转体积 | 绕 x 轴圆环法 `π∫|f²-g²|dx`；绕 y 轴壳层法 `2π∫|x|(f-g)dx` | 绕 x 轴要求 `0≤g(x)≤f(x)`；绕 y 轴要求区域在 y 轴一侧 |
| 反函数导数 | 导数、极限与函数 → 反函数导数 | 先求 `f(x0)=输入值` 的原像，再算 `1/f′(x0)` | 多个实原像、原像处导数为 0 时明确未完成，不任选分支 |
| 已知极限求参数 | 导数、极限与函数 → 已知极限求参数 | 由含参双侧极限与给定极限值反解唯一参数，并代回原式复核 | 参数须为不同于自变量的单个字母；左右极限不一致或多解时拒绝 |
| 变限积分求导 | 积分与面积体积 → 变限积分求导 | `F(x)=∫_{a(x)}^{b(x)} f(t)dt`，`F′(x)=f(b)b′-f(a)a′`；可选求值点 | 被积函数只含 `t`，上下限只含 `x`；指定求值点时用独立高精度数值积分复核 |
| 参数方程求导 | 导数、极限与函数 → 参数方程求导 | `dy/dx=(dy/dt)/(dx/dt)`；二阶导 `d/dt(dy/dx)/x′(t)`；可选一阶/二阶 | 要求 `x′(t0)≠0`；`x′(t)` 恒为 0 时不能写成 `y=y(x)` |
| 隐函数求导 | 导数、极限与函数 → 隐函数求导 | `dy/dx=-F_x/F_y`，二阶导由全微分推导；要求点在曲线上 | `F_y=0` 时拒绝；多分支需给出纵坐标；二阶导两种等价写法互相核验 |
| 渐近线 | 导数、极限与函数 → 渐近线 | 有理函数：分母实零点判垂直渐近线（可去间断点单独标注），无穷远极限与 `k=lim f/x`、`b=lim(f-kx)` 得水平/斜渐近线；符号结论 + 远点数值检查 | 非有理函数（含 sin、exp、sqrt）不能保证集合完整，明确拒绝 |
| 数列极限 | 导数、极限与函数 → 数列极限 | 通项 aₙ 只含指标 n，n→∞ 的符号极限；收敛、发散到 ±∞、振荡不存在分别标注；n=10²…10⁵ 数值观察 | 只研究 n→+∞，无单侧方向；数值观察只作参考 |
| 曲率与曲率半径 | 导数、极限与函数 → 曲率与曲率半径 | `κ=|y″|/(1+y′²)^{3/2}`，`R=1/κ`，并给出曲率中心 | `κ=0` 时明确不存在有限曲率圆；点处一、二阶导数须为有限实数 |

同时把两个原本只有内核、没有手动入口的题型暴露到界面：反函数导数、已知极限求参数。

## 2. 计算与核验口径

- 绕 y 轴体积不把区域折叠成“两侧相加”。当积分区间内部跨过 y 轴（`a<0<b`）时直接拒绝，提示拆分区域或更换旋转轴。
- 两条曲线之间区域先求 `f-g` 的全部实零点，按交点分段；面积取每段绝对贡献，体积按圆环/壳层公式逐段求和。
- 两条曲线绕 x 轴旋转要求两条边界都不低于 x 轴；否则区域跨越旋转轴，圆环法不成立，明确拒绝。
- 变限积分只做微积分基本定理与链式法则能直接核验的显式形式；指定求值点时，用 `mpmath` 高精度积分对 `F` 作中心差商复核，复核失败时把验证级别降为“未确认”，不伪造通过。
- 所有新题型沿用现有约定：无闭式结果、交点集合不完整、条件不足时保留原因，不输出数值近似冒充原题答案。

## 4. 建议的下一批顺序

1. **一元微分补全收尾**：渐近线（垂直/水平/斜）。可复用极限内核，但需要限定为有理函数或能证明有限奇点集的形式。
2. **积分应用补全**：平面曲线弧长、旋转曲面面积、极坐标面积/弧长。公式确定，但需接受“无初等原函数”时明确未完成。
3. **多元微分补全**：混合高阶偏导、抽象函数链式法则、多元隐函数。
4. **数列极限**：需要把序列对象与整数变量 `n` 接入现有极限内核，和函数极限分开标注。
5. **定积分物理应用**：功、压力、质心等需要单位与建模条件，建议最后做。
