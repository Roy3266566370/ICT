# 曲线与曲面积分手动输入（2026-11-14）

已接入“选择题型→填写曲线/曲面/场/区域与定向→确认原题→本地符号内核→两条路径或独立数值复核→保存重开→核对修改后重算”。保留原有声明式曲线/曲面积分与三大公式内核入口。

## 支持范围

| 类别 | 类型 | 输入 | 核验结果 |
| --- | --- | --- | --- |
| 曲线积分 | 第一类（对弧长） | x(t)、y(t)、z(t)，t 区间，f(x,y,z) | 弧长元、化为定积分、精确值与独立数值复核 |
| 曲线积分 | 第二类（对坐标） | 参数曲线、t 区间、P/Q/R、参数增大/反向 | 定向微分、精确值；反向整体变号 |
| 曲面积分 | 第一类·显式曲面 | z=z(x,y)，x 型投影区域，f | dS=√(1+zx²+zy²) dxdy、化为二重积分 |
| 曲面积分 | 第一类·参数曲面 | r(u,v) 三个分量，矩形参数域，f | |r_u×r_v| dudv、化为二重积分 |
| 曲面积分 | 第二类·显式曲面 | z=z(x,y)，x 型投影区域，P/Q/R，上/下侧 | 法向量 (-zx,-zy,1) 或反向、通量 |
| 曲面积分 | 第二类·参数曲面 | r(u,v)，矩形参数域，P/Q/R，r_u×r_v 正/反向 | 法向通量 |
| 公式 | Green | P(x,y)、Q(x,y)，x 型区域，正向/负向 | 边界积分与二重积分两条路径互验 |
| 公式 | Gauss | P/Q/R(x,y,z)，长方体区域，外法向 | 闭合曲面通量与散度体积分两条路径互验 |
| 公式 | Stokes | P/Q/R(x,y,z)，z=z(x,y) 曲面，矩形投影，上/下侧 | 边界环路积分与旋度通量两条路径互验 |

## 输入与边界

- 曲线为显式参数曲线 x(t)、y(t)、z(t)；平面曲线把 z(t) 填 0。t 区间要求下限小于上限；第二类曲线积分用“参数增大方向/反向”明确定向。
- 显式曲面的投影区域为 x 型区域：`a≤x≤b`，`y0(x)≤y≤y1(x)`；y 下界/上界可含 x。参数曲面为 `r(u,v)` 与 u/v 矩形参数域。
- 第一类曲面积分不需要定向；第二类显式曲面用上侧/下侧，参数曲面用 r_u×r_v 的正向/反向。
- Green 区域为 x 型简单区域，正向为逆时针、负向为顺时针；边界分段方向随区域定向同步。Gauss 首批仅长方体区域与外法向。Stokes 曲面为 `z=z(x,y)`、投影为矩形，上侧对应边界逆时针，下侧两侧同时变号。
- 曲线要求连续可微且 r'(t) 不恒为零；曲面要求法向量不恒为零；区域边界需在区间上为实值且下界不高于上界。
- 所有字段严格校验：缺失字段、额外字段、非法变量、反向区间、退化曲线/曲面均阻止确认。
- 无法得到有限闭式结果、数值复核不一致或定义域/奇点不能确认时，保留原题条件与未完成原因，不输出数值替代答案。

## 限制

- 曲线积分只支持显式参数曲线；尚未提供 y=f(x) 直接输入和一维隐式曲线。
- 曲面积分只支持显式 z=z(x,y) 与参数曲面；隐式曲面、曲面与曲面交线、一般闭合曲面通量未开放。
- Green 只支持 x 型简单区域；Gauss 只支持长方体区域；Stokes 只支持显式曲面在矩形投影上的情形。
- 法向量退化、区域越界、闭式原函数不存在或数值复核不一致时拒绝输出答案。
- 未修改认证、首页、全局样式与离线资源；未提交推送，未做全项目回归。


## 2026-11-14 修复

- 手动积分保留原式结构，不再把 `sqrt(t)^2` 等表达式化简掉定义域；曲线分量或被积表达式在参数区间内没有完整实定义时拒绝计算。
- 曲线积分增加参数取值范围上的被积函数/向量场实定义域检查，避免化简后对无定义区间给出错误积分值。
