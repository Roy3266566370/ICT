# 空间解析几何手动输入（2026-11-14）

已接入“选择题型→空间对象类型→填写点/向量/平面系数或曲面方程→确认原题→本地符号内核→结果与空间图形→保存重开→核对修改后重算”。保留文件识别与原有空间内核入口。

## 支持范围

| 类别 | 类型 | 输入 | 核验结果 |
| --- | --- | --- | --- |
| 向量 | 向量运算 | 两个三维向量 | 模、方向余弦、点积、叉积、夹角、数量投影、向量投影 |
| 向量 | 向量积与体积 | 三个三维向量 | 平行四边形/三角形面积、混合积、平行六面体/四面体体积、共面性 |
| 直线 | 两点确定直线 | 两点 | 方向向量、参数方程、对称式；两点重合拒绝 |
| 直线 | 点向式直线 | 点与方向向量 | 参数方程、对称式；零方向向量拒绝；零分量单独写成等式 |
| 平面 | 点法式平面 | 点与法向量 | 一般式方程；零法向量拒绝 |
| 平面 | 三点确定平面 | 三个点 | 由 (B−A)×(C−A) 求法向量与方程；三点共线拒绝 |
| 关系 | 两直线位置关系 | 两条直线的点与方向 | 重合/平行/相交/异面，夹角，平行或异面距离，交点 |
| 关系 | 直线与平面关系 | 直线点、方向与平面系数 | 直线在平面内/平行/相交，线面夹角，距离，交点 |
| 关系 | 两平面位置关系 | 两个平面系数 | 重合/平行/相交，夹角，平行距离，交线 |
| 距离 | 点到直线距离 | 点与直线 | 叉积公式求距离与垂足 |
| 距离 | 点到平面距离 | 点与平面 | 距离公式与沿法向量的投影点 |
| 投影 | 直线在平面上的投影 | 直线与平面 | 投影直线方程；垂直时退化为交点；平行时保持方向 |
| 曲面 | 切平面与法线 | `F(x,y,z)=0` 或显式方程，曲面上一点 | 梯度法向量、切平面、法线；点不在曲面上或梯度为零拒绝 |
| 曲面 | 二次曲面识别 | 二次曲面方程 | 椭球面、单/双叶双曲面、椭圆锥面、椭圆/双曲抛物面、三类柱面及退化类型；配方中心与标准形 |

已有的 `point_plane_distance`、`point_line_distance`、`line_plane_intersection`、`plane_plane_angle` 内核入口保留，后两者分别作为直线与平面关系、两平面关系的别名，原有验收断言不变。

## 输入与边界

- 点与向量写成 `a,b,c`，平面写成 `a,b,c,d`（表示 `ax+by+cz+d=0`），分量可为分数、`pi`、根式等有限实常数；不允许空分量或未知符号。
- 所有类型严格校验字段集合：缺失字段、额外字段、零向量/零法向量、共线三点、非实数坐标均阻止确认。
- 每个类型的预览阶段即调用同一符号内核，确认页展示类型、完整条件与题目文本；修改任一条件会使确认失效。
- 曲面方程最多一个等号。切平面要求点精确满足 `F(P)=0`，且 `∇F(P)≠0`；奇点不生成切平面。
- 二次曲面首批只支持不含 `xy`、`yz`、`zx` 交叉项的多项式方程；含交叉项时明确要求先做正交变换，不自行旋转坐标。三个平方项可含一次项并自动配方；两个以上剩余一次项、高于二次的方程、平面方程拒绝识别。
- 退化类型（点、直线、相交/平行平面、空集）明确标注为退化二次曲面，不绘制替代曲面。
- 空间图形是对曲面或直线/平面的有限范围采样；距离、夹角、交线、方程与分类由符号计算给出，不以图形判定。

## 实际算例

| 题目 | 结果 |
| --- | --- |
| `a=(1,2,3), b=(4,5,6)` | `a·b=32`，`a×b=(-3,6,-3)`，夹角 `acos(16√22/77)` |
| `A=(0,0,0), B=(1,2,3)` | 方向 `(1,2,3)`，对称式 `x=y/2=z/3` |
| 过 `A(1,0,0)、B(0,1,0)、C(0,0,1)` 的平面 | `x+y+z−1=0` |
| 点 `(0,0,0)` 到平面 `x=2` | 距离 `2`，投影点 `(2,0,0)` |
| 点 `(0,1,0)` 到 `x` 轴 | 距离 `1`，垂足 `(0,0,0)` |
| 直线 `x` 轴与过 `(0,1,1)` 的 `y` 向直线 | 异面，距离 `1`，夹角 `π/2` |
| 直线 `(0,0,1)+t(1,0,1)` 到平面 `z=0` 的投影 | `y=0, z=0` |
| 平面 `x=0` 与 `y=0` | 相交，夹角 `π/2`，交线过原点方向 `(0,0,1)` |
| 曲面 `z=x²+y²` 在 `P(1,1,2)` | 切平面 `2x+2y−z−2=0`，法线方向 `(−2,−2,1)` |
| `x²/4+y²/9+z²=1` | 椭球面 |
| `x²+y²−z²=0` | 椭圆锥面 |
| `x²+y²=1` | 椭圆柱面 |
| `x²+y²−z=0` | 椭圆抛物面 |

## 限制

- 曲面类型只覆盖切平面/法线与不含交叉项的标准二次曲面；一般旋转曲面、曲面与曲面交线、主曲率等尚未开放。
- 二次曲面识别不做坐标旋转；交叉项方程会拒绝而不是猜测类型。
- 空间图形是有限采样，不表示整张曲面的完整范围；退化类型的图形可能为空。
- 未修改认证、首页、全局样式与离线资源；未提交推送，未做全项目回归。
