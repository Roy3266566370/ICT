# 象生 v0.3 重做规范：原页底图 + 原位动态重建

> 本文件是**唯一施工依据**。与 v0.2 的 plan.md 冲突时，以本文件为准。
> 用户验收原话：「用户上传 PPT 后，首先获得保持原始版式的网页阅读结果。在不破坏页面视觉结构的前提下，将识别并确认的图示、数值和关系升级为可操作对象。调整参数后，相关图形、公式和结论在原页对应位置同步更新，并支持过程播放与恢复原始状态。」

## 0. v0.2 为什么被判"效果差"（必须逐条避免）

| 问题 | v0.2 的现状 | 本次必须做到 |
|---|---|---|
| 原页没有真正还原 | 页面被排成段落和元素清单 | 用 PowerPoint 渲染真实整页位图，**默认态就是原页** |
| "整页预览"不是整页 | 把页面第一张插图当页面图 | 每页一张真实整页 PNG |
| 有 rendering 阶段但没渲染 | 只有结构解析 | 该阶段真的产出整页图，**图出即可读**，不等识别 |
| 原材料与交互分开 | 两个界面/两套东西 | **同一页**：默认原页，点击图示才激活动态层 |
| 新上传图片链路不完整 | 依赖预置 `fixtures/ppt` | 从上传的 pptx 中**提取并保存**图片，按 material_id 隔离 |
| 识别范围窄且写死 matrix_2d | 正则 + 固定模板 | 区域识别按页产出候选，用户确认；不支持就明确标"仅静态阅读" |
| 阅读入口被阻断 | 先判断知识对象才能看原文 | **无知识对象也能读原文** |

## 1. 三级完成等级（本次目标：稳定达到第 2 级，第 3 级做 S6/S9 演示）

| 等级 | 用户得到什么 |
|---|---|
| L1 原貌阅读 | 完整、清晰的原 PPT 页面，可翻页、可缩放 |
| **L2 原位交互（本次核心）** | 原图所在区域变成可调对象，页面布局保持连续 |
| L3 关联推演（演示一个） | 多页属于同一对象的图/数值/结论共同更新 |

## 2. 首版六项基础条件（验收即按此打勾）

1. 真实上传后能完整阅读：保留页数、版式、文字、图片；翻页、缩放；未识别页面仍可读。
2. 原图所在位置可交互：至少一类图示被动态对象替换，保持原页布局；可点击、拖动、调参。
3. 参数、图形、结果一致：改一个输入 → 箭头、公式代入、数值、相关结论一起更新。
4. 能看见变化过程：播放 / 暂停 / 单步 / 重置，中间状态有意义。
5. 转换结果可确认与纠正：能确认区域与参数，识别错了能改，不支持的有明确状态。
6. 操作可恢复与复现：恢复原始参数；保存一次运行后重开得到相同输入与结果。

## 3. 渲染链路（后端）

### 3.1 引擎优先级
1. **Windows + PowerPoint（COM）**：`Dispatch('PowerPoint.Application')` → `Slides(i).Export(png, 'PNG', 1920, 1080)`。
   本机已验证可用（24 页全部导出成功，中文无乱码）。
2. **LibreOffice（备选）**：`soffice --headless --convert-to pdf` + PDF→PNG（若装了 pymupdf）。
3. **兜底**：结构化 SVG 还原（仅当以上都失败），必须在产物里标 `render_engine: "svg_fallback"` 与 `fidelity: "low"`，前端明确提示"本页为结构还原，可能与原版式有差异"。

渲染必须在**上传后立即执行**，产出页图后材料状态即可 `readable`；识别与编译在其后异步进行。**不得**因为识别失败而让页面不可读。

### 3.2 产物目录（按 material_id 隔离）
```
backend/data/renders/<material_id>/
  pages/s01.png ... s24.png          # 整页 1920x1080
  pages/s06_erased.png               # 该页所有交互区域已擦除的底图
  assets/<asset_id>.<ext>            # 从 pptx 提取的原始图片（按 sha1 去重）
  regions.json                       # PageRegion[]
```

### 3.3 擦除规则（禁止"盖白块放通用图"）
- 原图是**独立图片**：用该页背景色（取样自页图四角，实测 `#F6F3EC`）填充该图片 bbox，生成 erased 版；动态层在同 bbox 重建**语义对应**的图示。
- 原图由**多个形状**组成：只擦除确认要替换的形状集合，其余保留。
- **不可分离**（复杂背景/渐变）：整块区域作为一个 region 整体重建；无法可靠重建时 `status: "static_only"`，该区域保持静态阅读，绝不能硬盖。
- 擦除前必须校验：bbox 四边外 2px 环带的像素方差 < 阈值（纯背景）；否则判"不可分离"。

## 4. 数据契约：PageRegion

```jsonc
{
  "region_id": "rgn_s06_vectors",
  "material_id": "mat_matrix_courseware",
  "page": 6,
  "bbox": { "x": 0.58, "y": 1.27, "w": 6.67, "h": 4.69 },   // 英寸，相对 13.333x7.5 页面
  "coordinate_system": { "view_box": [1920, 1350], "origin": [640, 770], "unit": 150, "y_axis": "up" },
  "script_id": "matrix_eigen_2d",          // 前端动态组件注册名
  "status": "confirmed",                    // pending | confirmed | static_only | unsupported
  "original_params": { "a11": 2, "a12": 1, "a21": 1, "a22": 2, "vectors": [[1,0],[1,1],[1,-1]] },
  "linked_texts": [
    { "element_id": "p06_e03", "bbox": {"x":7.67,"y":2.90,"w":1.75,"h":0.23},
      "template": "({x0}, {y0}) → ({x1}, {y1})", "kind": "result" }
  ],
  "assets": { "page_image": "pages/s06.png", "erased_image": "pages/s06_erased.png" },
  "notes": "S6 左图；原矩阵由三条映射反解，provenance=inferred"
}
```

- `script_id` 白名单：`matrix_eigen_2d`、`matrix_columns_2d`、`matrix_order_2d`、`svd_steps_2d`、`det_area_2d`。
- 每个 region 必须能回答：**属于哪页、区域在哪、内部坐标系是什么、原始参数是什么、用什么组件渲染、哪些文字要跟着变**。

## 5. 前端宿主契约

```ts
// frontend/src/regions/types.ts
export interface RegionRendererProps {
  region: PageRegion;
  params: Record<string, unknown>;          // 已合并 original_params 与用户改动
  onChange: (patch: Record<string, unknown>) => void;
  stage: 0 | 1 | 2;                         // 0 原像 / 1 变换中 / 2 完成
  reducedMotion: boolean;
  /** 把"当前计算结果"回传给宿主，用于原位替换 linked_texts */
  onLinkedTexts: (texts: Array<{ element_id: string; text: string; changed: boolean }>) => void;
}
```

宿主 `<PageCanvas region={...}>`：
- 用 `bbox / 页面尺寸` 换算百分比绝对定位；底图与动态层共用同一套变换（缩放只改容器尺寸，不改内部坐标）。
- 动态层 SVG：`viewBox = coordinate_system.view_box`，`preserveAspectRatio="xMidYMid meet"`；数学坐标 `(x,y)` → `(origin.x + x*unit, origin.y - y*unit)`。
- **默认态渲染未擦除的原页**；点击/键盘 Enter 激活后切到 erased 底图 + 动态层（交叉淡入 250ms）。
- 切换页面、切换对象**不清空参数**。

## 6. 工作台布局（替换 v0.2 的三栏）

| 区域 | 内容 |
|---|---|
| 左侧 | 24 页缩略图 + 页码；当前页标"可交互"或"仅阅读" |
| 中央 | **保持 16:9 原比例的当前页**，最大宽度优先；缩放 50%–200%；可拖动平移（放大后） |
| 右侧 | 选中对象时才出现**少量关键参数**（默认收起为 42px 抽屉）；无选中时不显示 |
| 底部 | 播放 / 暂停 / 单步 / 进度（步骤 0-2）/ 重置 / **恢复原稿** |
| 次级面板 | 来源、识别说明、计算检查、运行记录 —— 折叠在"详情"里，默认关闭 |

`revision`、`element_id`、bbox、模板标识等实现信息**只能出现在"详情"面板**，不得占据主阅读区。
移动端：页面保持比例（横向可缩放查看），参数变抽屉，不得把桌面三栏压成一张小图。

## 7. 视觉规范（必须对齐原页）

- 页面背景 `#F6F3EC`；轴/刻度 `#8B9AB3`；强调橙 `#C4622D`；深藏青 `#16233A`；原像虚浅 `#A9B4C7`。
- 线宽：轴 1.8、原像虚线 3.2（`dasharray 9 8`）、像实线 3.2、椭圆 3.2（`fill-opacity .055`）。
- 字号：坐标标注 26、轴刻度 20、单位圆/椭圆说明 25-26、倍数标注 25（带 `#F6F3EC` 描边 5px 做底）。
- 教学图层**一个都不能少**：坐标轴 + 刻度数字 + 原点实心点 + 单位圆虚线 + 变换后椭圆 + 三条原向量（虚线+端点+标注）+ 三条像向量（实线+箭头+标注）+ 特征倍数（×λ）。

### 7.1 标注防遮挡规则（v0.2 原型踩过的坑）
- 原像标注与像标注**必须分区**：原像标注贴端点内侧偏移，像标注贴箭头外侧偏移。
- 当 `A·v ≈ v`（特征向量，原像与像完全重合）：只画一条线，标注合并为 `(1,-1) 不动 ×1`，**不要**画两条完全重叠的线。
- 倍数标注加背景描边，且放在像向量 60% 处的外侧，不得压在线上。
- 刻度只画落在区域内的整数，数字不得互相重叠（间距 < 28px 时隔一个画）。
- 所有标注做一次"包围盒不重叠"自检；重叠时按优先级降级（先隐刻度数字，再移标注）。

## 8. 参数 / 图形 / 文字三者同步

每个 region 的文字分三类，界面上必须能区分：
1. **原文固定内容**（页图里本来就有的，不覆盖）
2. **当前参数计算结果**（偏离原始值时，原位覆盖并加"当前值"标识；恢复原值后自动隐藏覆盖层）
3. **只在原始条件下成立的说明**（如 S6 右侧"特征值 λ = 3"）：参数改变后**不得继续呈现为当前结论**，覆盖层需显示"（原页为 A=[[2,1],[1,2]] 时）"。

`linked_texts` 的模板用占位符（`{x0}` 等），由组件提供数值；宿主负责替换与"当前值"标记。

## 9. 五个页面必须达到的效果

| 页 | 动态内容 | 现场必须看到 |
|---|---|---|
| S6 三条向量 | 重建圆/椭圆与三条向量；端点可拖 | 哪些方向被掰歪、哪些保持共线（×3 / ×1 可见） |
| S9 各列与基向量 | 拖动两个基向量的像反推矩阵列；调输入向量组合系数 | 矩阵各列决定整个空间去向 |
| S10 乘法顺序 | 两条路径同步播放旋转与伸缩 + 中间状态 | 先转后拉 / 先拉后转 的差别 |
| S14 SVD 三步 | 按 Vᵀ → Σ → U 播放，保留标记点 | 圆旋转外观不变，但标记点揭示第一步 |
| S18 行列式与面积 | 连续演示拉伸/剪切/压缩/翻转，更新面积与符号 | 面积倍率与定向变化可直接观察 |

播放语义：旋转按角度、伸缩按倍率、组合变换分两步；**不得**把任意系数的插值解释成原文描述的运算过程。
