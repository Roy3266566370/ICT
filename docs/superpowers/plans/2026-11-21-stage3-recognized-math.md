# 阶段3：图片参数识别与原位活图

以用户清单和仓库原始《用空间视角理解矩阵运算.pptx》为验收依据；沿用阶段2数学节点，不硬编码课件页码或图片哈希对应的答案。

1. 扩展视觉客户端为逐页、元素级多图识别：原始裁图、元素标识、位置和本页文字一起发送。透明PNG先按浅底合成，矩阵和大图一起理解。预算在请求前扣除，故障保留原图。
2. 新增 `documents/auto_math.py`：验证OCR矩阵维度、数值、每个单元格位置、置信度与加法等式；验证大图矩阵、向量、原多边形、比较矩阵、换基和累计步骤。只有确定的元素才映射成math_scene。原图、来源与识别报告保留。
3. 原位数字使用 image 节点的 `matrix_ocr`，最多6×6支持非方阵；每个单元格有相对裁图bbox。二维小矩阵可通过matrix_source驱动相关数学图。加法结果随操作数计算。
4. 数学节点按语义扩展多向量、面积多边形、运算次序对比、换基与分步累计矩阵。仅对同一行、箭头分隔且语义步骤确认的图片合并为一个舞台。底图分离准备完成后原子替换，失败不覆盖；并发教师修改优先。
5. 前端复用mafs与本页演示overrides，支持参数编辑、拖动、原位播放、步骤按钮和重置。保存载荷与后端校验同步扩展。
6. 测试先覆盖：非法/不确定输出保留、矩阵和加法OCR、步骤布局、真实参数、并发保存保护；再用真实模型与真实PPT上传验收P05/P06/P09/P14/P18/P22，并检查小矩阵P06/P11/P22。P17实际图片内容须以源图为准，不能凭清单猜造矩阵。

前后端按以上数据接口分工；最终统一检查类型、单元测试、网站与离线构建及真实浏览器操作。模拟模型测试只证明协议与降级，不当作真实识图验收。
