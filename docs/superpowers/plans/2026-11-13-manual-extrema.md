# 多元极值手动流程实施计划

**Goal:** 按已授权的手动输入方案，打通二元局部极值和单等式约束极值，保留全部原题条件及未完成状态。

**Architecture:** 复用 complete_extrema 的驻点与 Hessian 判别、constrained 的加边 Hessian 和安全解析；专用 calculus 任务统一确认、保存、核对及结果展示。首批用多项式目标与约束保证全域光滑，并用精确多项式方程组检查候选完整性；其他表达式保留原题但明确未完成。

**Constraints:** 不改现有未提交的认证、首页、Space及原型界面；不提交推送；不将局部极值当全局最值；不以乘数方程代替奇异约束点检查。

1. 写后端真实题目测试并先确认失败：多个驻点、极小/极大/鞍点、退化、无驻点；约束代回、乘数分类、奇异点和不完整候选；不等式/多约束/夹带额外条件拒绝。
2. 新增 extrema.py 专用编排与证明状态，接入 kernel_models / solvers / manual / API task。未完成结果仍可保存并显示已核验事实。
3. 扩展 manualInput 与已有 Composer、Review、Result、Canvas；冻结已确认任务/变量，修改目标或约束必须重算。复用数学键盘，不引入优化示例轨迹。
4. 前端契约测试、类型检查；浏览器实际题验证确认、结果、未完成、保存重开、修改约束重算以及保留文件/示例入口。
5. 重跑多元微分及相关高数回归，检查差异与未触碰界面文件哈希，记录支持范围和验证结果。
