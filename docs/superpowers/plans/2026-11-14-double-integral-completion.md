# 二重积分模块继续补齐

沿用现有手动输入、确认、保存与核对流程，不改认证、首页及离线资源，不提交工作区既有改动。

1. 扩展反常积分：新增 `polar_improper`（有限极角、常数非负极径、允许无穷上限）与 `strip_improper`（有限曲边区域）输入；检查每个原始子表达式的实定义域，再代换为参数矩形并核验绝对收敛，不用主值抵消。反常积分不显示有限截断黎曼和。
2. 新增 `affine` 变量代换：输入 `x_map(u,v), y_map(u,v)` 及u/v完整区域；核验映射为仿射、det不为0，乘Jacobian绝对值，保留原式子表达式定义域，展示映射区域。由独立模块 `double_affine.py` 提供 `preview(c)` 与 `solve(c)`。
3. 新增应用字段 `application=mass|centroid|inertia|probability`：原被积函数为密度，支持既有有限单片/分片/极坐标；证明密度非负，质心要求正质量，概率要求整个支持区域积分为1并核验事件区域包含关系。由独立模块 `double_applications.py` 提供 `preview(c)` 与 `solve(c)`，不可把未归一化积分当概率。
4. 统一结果契约：普通solution字段加 `double_extension={kind,title,facts:[{label,latex}],values:[{id,label,latex,value:number|null}],notes:[],region_points?:[{x,y}]}`。`preview`返回task/label/conditions/latex/question。各模块未完成时返回完整条件与unsupported，不用示例补答案。通用build/evaluate集成由主代理负责。
5. 前端补齐各模式字段、共享键盘、确认失效、结果与区域示意；保存与核对重算沿用扁平字符串条件，不迁移旧题。
6. 各模块先编写失败用例，再实现；分别专项验证并做独立审查，最终联合后端/前端/浏览器、类型检查、生产构建。

7. 继续覆盖上一轮清单中的更一般换序与非线性代换：普通边界允许可核验的初等函数，函数值域必须覆盖整个实际区间；临界点、单调分支和反函数齐全时按有限单元证明换序。非线性变量代换先支持可证明一一对应的三角形结构/分离映射，拒绝重复覆盖，证明Jacobian符号与有限退化集合。

Ruling: 先实现可严格核验的仿射代换、参数域反常积分与应用流程；任意非线性映射、任意隐式区域和不可判定符号积分保留未完成，不宣称任意题型都可自动求解。理由：映射可逆性、区域重数和绝对收敛不可用抽样代替；错误取舍的代价是后续扩展算法，不是输出未经证明的答案。
