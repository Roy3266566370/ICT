# 万象工坊：高数搭建扩充

用户范围：优先丰富高数可搭建内容，完成积木、模板、引导、保存与发布链路。沿用 React/TypeScript 画布与现有后端，不增加依赖。

方案：扩充现有类型化端口与图求值器。相比只增加模板，这能支持自由搭建；相比嵌入独立实验页，这能复用连线、撤销、封装和分享。

## 实现顺序与验收

1. 先添加数值行为测试：函数参数传递、可去间断点左右趋近、跳跃/发散不输出候选、尖点不可导、带符号积分/几何面积/反向区间、泰勒近似及不光滑点。
2. 复用 labs/expr.ts 的受限解析器，实现高数纯函数计算。导数与泰勒系数使用截断幂级数自动微分，比较左右分支；积分与极限标注数值近似。定义域异常返回明确错误，不使用 eval。
3. 新增 function 类型端口和六种积木：函数源、函数图像、极限观察、导数切线、黎曼积分、泰勒近似。标量驱动观察点，导数/积分结果输出标量，泰勒输出函数，可继续连线。后端保留复合积木的 function 端口。
4. 新增七个带探究步骤、预期观察与记录区的模板：函数变换、重要极限、左右极限、导数定义、定积分、积分与面积、泰勒展开。工坊提供分类筛选、难度/用时/搭建链路；画布提供高数分类和简要指导。
5. 运行计算与图求值测试、后端工坊保存发布测试、前端完整测试和构建，再用浏览器检查模板创建、参数联动、刷新、发布与改造、窄屏入口。

## 数学边界

仅一元实函数和有限区间的数值实验。本轮不新增多元微积分或符号求解器。极限观察是数值证据，不证明极限存在；导数和泰勒系数自动微分并检查左右分支一致；积分不自动解释反常积分或柯西主值；泰勒最多五阶，保留浮点误差，不声称任意函数展开收敛。部分复杂边界表达式保守拒绝自动微分，仍可用函数图像观察。
