# 二重积分手动流程实施计划

目标：按已授权方案接入直角坐标单片区域、两种积分次序、完整积分限、确认计算、区域与过程展示、保存及核对重算。

复用：double_integral.compile_model / _validate_strip / solve_double_integral，前端 evaluateDoubleIntegral / DoubleIntegralCanvas，以及共享数学输入、手动确认、结果和Review组件。不新增依赖，不修改认证、首页、Space及原型界面，不提交推送。

输入契约：task=double_integral；字符串字段integrand、outer_variable(x/y)、outer_lower、outer_upper、inner_lower、inner_upper。内层变量由外层唯一确定；外层上下限是有限实常数，内层上下限只能依赖外层变量。不得默认下界0、自动交换上下限或丢弃其他条件。手动切换次序清空四个边界并取消确认，不宣称自动推导同一区域的换序表达。

1. 先写失败测试：矩形、三角形、双非零边界、曲边区域、两种次序同一区域、精确端点、零面积；拒绝缺限、反向/交叉边界、自依赖、额外条件。
2. manual_double_integral.py将扁平字段映射到现有数组内核，保存原始字段；区域全区间检查与被积函数连续实定义核验分开，不能用抽样通过代替全域证明。无法完成时保存未完成状态及区域事实。
3. 接入manual/API并扩展现有输入、共享键盘、确认、Review和结果；完整复用现有区域阴影/切片画布，未完成不构造积分曲线或示例答案。
4. 前端契约、类型检查、浏览器实际题、保存重开、改限重算、切换次序取消确认及原有高数回归。
5. 检查差异与既有界面哈希，记录验证证据和限制。分片、极坐标、自动换序和反常积分后续扩展，不压成单片丢条件。
