# 经典 PPT 原图直接交互实施计划

**用户流程**：上传 PPTX → 后台自动识别和准备 → 打开经典 PPT → 直接拖原图位置上的箭头，调整线长和颜色。可操作的图默认处于交互状态，打开页面或开始放映都不需要点转换、激活或确认应用。

**实施范围**：沿用经典工作台的 SceneDocument、FreeDeckEditor 和 DeckPlayer。活页讲义继续处理 PDF、图片和文本。原始 PPTX 和页图保留供对照。新版动态舞台的历史计划已停止。

## 1. 统一上传入口

- [x] 首页 `LivingUploadPanel.tsx` 与 `LivingPagesPage.tsx` 复用同一套上传分流。单份 PPTX 进入 `/materials/:materialId/work`，处理状态沿用经典播放器。含 PPTX 的多文件选取提示逐份上传。其他材料沿用讲义流程。
- [x] 用《用空间视角理解矩阵运算.pptx》分别从两个入口上传，验证都进入经典工作台，原有改字、插入椭圆、交互配置和全屏放映仍可用。

验收记录：首页及活页入口分别上传指定的真实 24 页 PPTX，浏览器测试 2 项通过。两次均通过改字、椭圆、换基交互、保存刷新和放映检查。

## 2. 在经典舞台加入可操作的矢量对象

- [x] SceneDocument 增加可选的线段和箭头对象，存储稳定 ID、两端坐标、颜色、线宽、线型及箭头样式。由 `ScenePageView` 共享渲染，`FreeDeckEditor` 和 `NodeProperties` 提供拖端点、输入精确长度与角度、改色和线型、撤销及保存。
- [x] DeckPlayer 在原页图形的位置显示可拖端点及就地长度、颜色控件。拖动更新图形，放映中的调整为会话状态，可一键重置。作者在编辑器保存的是课件默认值。放映事件区分拖动、输入和翻页。
- [x] 先用手工插入的箭头打通上述编辑与放映链路。手工插入是独立的作者能力，自动识别的图无需经过此步骤。

验收记录：《用空间视角理解矩阵运算.pptx》编辑器新建线条和箭头，拖端点、设定长度、颜色和虚线，刷新读回。放映期间拖端点、调整长度、颜色和点线，确认不翻页，重置恢复保存值。几何单测和文档后端测试通过。

## 3. 上传后自动准备原图交互

- [x] 在经典上传流程中自动准备原图箭头。原生直线连接线读取 PPTX 坐标和样式。独立嵌图用像素定位并校验彩色直箭头，识别不确定时用 Qwen 补充候选，每份文档最多 4 次视觉请求。
- [ ] 自动验证图元坐标、关系、覆盖区域和来源。验证通过后写入同一 SceneDocument，保留原图引用，并在原位置默认显示可操作对象。原生对象或独立图片按对象替换显示，合在页图里的内容须有可靠的替换区域。重复执行不得创建副本，也不得覆盖作者已保存的修改。
- [ ] 原页可读后即可浏览。未完成识别的页仍展示原稿与准备状态，准备成功后当前打开页自动可操作。识别失败、关系不明确或替换可能遮住邻近内容时保留原稿，并向作者说明具体原因。作者可以修正识别结果，成功对象的首次操作不设确认门槛。
- [x] 首批支持原生直线、箭头和嵌入图片中的二维向量示意图。「标准基 vs 斜基」支持固定终点时拖动 b₂ 自动重算斜基坐标及辅助线，基退化时显示状态。播放时支持两段路径顺次伸展。切换原图对照保留当前的线条调整。

当前交付范围：识别成功的箭头默认原位可拖，可调线长和颜色，并可切回原图。复杂背景、组合或弯折箭头按原稿展示。符合双坐标系结构的换基图会自动启用坐标联动和两步合成。直接上传原始换基 PNG 已验证原位拖动 b₂、固定终点、实时更新坐标和虚线、分步播放及切回原图。

新增验收使用独立绘制的换基 PNG 和嵌入原始换基图的 PPTX，均从活页上传进入经典工作台，打开对应页即可拖动 b₂。浏览器验证了实时更新坐标和虚线折点、固定终点、两步播放、改线长和颜色、原图对照往返保留调整。像素检查覆盖了新图 b₂ 原笔画及旧辅助虚线的清理，以及原样图 b₂ 关键像素的清理。

## 4. 回归与交付门槛

- [ ] 验收一份含原生箭头的 PPTX，以及一份将「标准基 vs 斜基」嵌为图片的 PPTX。两份均从正常上传入口进入，完成准备后直接在原页拖动箭头、调线长和改色。测试流程禁止调用手动转换或激活入口。
- [ ] 换基验收从 b₂=(1,1) 拖到 (2,1)。固定终点保持 (2,1)，斜基系数变为 (0,1)。验证分步合成、切回原图、缩放时端点定位准确，以及替换不产生重影或遮挡邻近标题。
- [ ] 再用一张未专门适配的同类图测试识别；覆盖并发修订、重复识别、模型不可用、低置信候选和旧课件。验证编辑后保存、刷新和放映一致。
- [ ] 公开分享和离线文件复用相同的对象数据与渲染。断网验证端点拖拽、长度、颜色及动画仍可用，无需现场请求模型。

按「统一入口 → 矢量对象与控件 → 后台自动准备 → 分享和离线验收」推进。单独生成可嵌入的 AI 实验是后续扩展，首版验收以直接操作原有图形为准。
