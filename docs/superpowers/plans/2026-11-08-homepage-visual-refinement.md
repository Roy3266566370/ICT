# 网站首页与个人主页视觉优化实施计划

**目标：** 重点优化网站首页，同时统一个人主页的视觉质量；保留现有上传、实验、账号和资料编辑能力。

**设计：** 延续当前「万象 WANXIANG」品牌与纸面主题。采用暖白纸面、墨色标题、陶土橙点缀；通过不对称首屏、真实交互演示、编号与细线组织内容。使用现有 React / TypeScript / CSS Modules 与原生 SVG，不增加依赖，不引入外部图片、字体或虚构业务指标。

**方案判断：** 仅调整颜色难以改善信息层次；全面更换品牌与技术栈超出本次目标。采用局部重构页面结构并复用现有功能的方式，由执行者负责具体视觉选择。

**范围与边界：** 网站首页 `/` 与个人主页 `/space`。统一导航增加可选 `appearance="studio"`，默认样式保持兼容。个人资料随账号保存，作品仍属于当前浏览器会话；页面必须保留这一真实说明。不修改账号、验证码、上传或数据权限逻辑。

**工作区：** 当前目录没有 Git 元数据，直接在现有目录工作，修改前备份目标文件到 `verify/home-visual-20261108/before/`。不创建仓库或提交。

- 360px 至 1440px 无横向溢出，移动导航可以使用。
