# 上传课件的编辑与交互修复

用户复测《用空间视角理解矩阵运算.pptx》失败：当前只有一条交互规格，没有原始内容编辑入口。这轮修复以同一份课件为主要验收输入。

## 交付行为

1. 上传后的材料提供明确的编辑模式。点击原页文字、公式或图表选择元素，修改后保存并重新打开。
2. 编辑写入材料自己的工作副本，保留上传原件；重新解析、重建预览和交互，避免图片上叠旧文字。
3. 文字/表格/原生图表可编辑真实数据；图片公式允许查看来源、修正识别文本并绑定受限交互，不能伪称已自动识别。
4. 自动识别从原生文字扩展到局部图片 OCR；识别到的数值和关系必须带真实元素坐标与识别状态。无充分依据的候选必须可确认或修正。
5. 交互直接在选定的原页区域生效；修改矩阵/向量后图形、数值、公式一起更新。
6. 已发布的页面图保持版本独立，后续编辑不能悄悄改变旧分享。
