## 4. 样本与标注设计

### 4.1 首批规模与划分

| 材料类型 | 数量 | 划分与用途 |
| --- | ---: | --- |
| 真实陌生 PPTX | 30 份 | 开发 12、校准 6、盲测 12；两个重点方向各约 15 份 |
| 受控变体 PPTX | 10 份 | 跟随原件所属集合；仅作稳健性测试，不增加独立课件计数 |
| 负例与边界材料 | 10 份 | 开发 4、校准 2、盲测 4；语义负例与异常文件分开统计 |

真实材料尽量覆盖至少 3 位教师或独立课程来源，以及原生公式、表格、组合对象、图片公式和不同版式。记录实际取得的覆盖，不能因数量凑齐就声称全部覆盖。

每个拟重点宣传的模板，正式验收集中争取至少 20 个标注区域、来自至少 5 份独立 PPT。独立文件数、来源组数及区域数分别统计；不足时保留试点说明。当前规模优先保障两个重点模板或场景，不要求十个新增模板同时成熟。

拟新增材料目录：`E:/代码/ICT/fixtures/competition-20261108/`，包含 `manifest.json`、`labels/`、`dev/`、`calibration/`、`blind/`。存在版权或传播限制的原件放在受控存储位置，清单保留定位信息，不直接加入公开交付包。

| 字段 | 含义 |
| --- | --- |

## 5. 指标定义与验收口径

### 5.1 先对齐来源，再计算成绩

评估器必须在不读取 `expected_template` 的条件下，将预测与任务实例对齐：

1. 使用页码与冻结映射后的原文件对象标识进行定位；对象标识不同的两个题目不能只因同页就匹配。
2. 纯图片区域可使用同页 bbox，默认 IoU 阈值为 0.5，并核对证据摘录或图片区域；阈值只允许在校准集确定。
3. 多对多歧义按来源重叠权重进行确定的一对一分配；模板和参数答案不能参与分配。不能唯一分配的样本输出 `alignment_ambiguous`，列入待裁决，不计为正确。
4. 对齐后才比较模板、必需参数、单位与参数级来源；所有未匹配自动执行结果、重复结果和超过标注允许数量的方案计为 FP。
5. 候选 Recall@5 使用实际返回的有序候选列表。最终选择正确率与候选中是否包含正确模板分开报告。

“正确自动执行”同时要求：允许的模板和版本、全部必需参数及单位、有效来源、执行条件、数值/轨迹结果均符合标注。来源覆盖率只说明有没有引用；来源正确率还要说明引用是否支持该字段。

识别联合正确率与执行正确率分列：只运行解析和规划时，可以报告“模板＋必需参数＋来源”的识别联合正确率；只有实际编译并求值后，才能报告自动执行精确率和数值/轨迹正确性。未执行的样本标为 `not_run`，不能借用单独内核单测的结果填成该材料已执行成功。

### 5.2 报告指标

| 指标 | 分母与规则 | 验收目标 |
| --- | --- | --- |
| 自动执行精确率 | 正确自动执行数 / 全部自动执行数，包含多余与重复结果 | ≥95% |
| 可执行任务召回率 | 正确自动执行的任务数 / 标注应执行任务数 | ≥85% |
| 参数正确率 | 正确的必需参数项 / 所有应提取必需参数项；缺失计错 | 单独报告，不替代联合结果 |
| 来源覆盖率 | 已引用来源的必需参数项 / 全部必需参数项 | 100% |
| 来源正确率 | 引用确实支持对应字段的必需参数项 / 全部必需参数项；缺失也计错 | ≥95% |
| 待核对与负例处理 | 分别统计应核对任务的阻断率、语义负例不执行率、异常文件拒绝情况 | 严重误执行为 0 |
| 数值与轨迹 | 整数/离散结果精确一致；浮点默认 abs=1e-9、rel=1e-6；既有黄金契约更严格时沿用 | 重点场景全部通过 |
| 跨页关系 | 对有人工标准的候选关系单独计算精确率与召回率 | 若保留原申报承诺：≥90% / ≥85% |
| 版本与传播一致性 | 保存、重载、分享、离线及工程包的逐项比对 | 声明支持的重点能力全部通过 |
| 准备耗时 | 20 页且≤20MB，上传完成至可核对/可执行；首次可读时间另记 | 对照原申报≤180秒 |
| 调参耗时 | 输入事件到相关图形和数字完成更新，记录 P50/P95 | 对照原申报 P95≤150ms |
| 人工负担与成本 | 核对次数、核对时间、模型调用数、token、实际费用或不可得原因 | 如实报告 |

自动执行分母为 0 时精确率记 `not_applicable`，不能填 100%；应执行任务数为 0 时召回率同理。空候选对有标准任务计漏识别。未知、跳过、执行失败和缺文件不得静默消失。

严重误执行包括：缺必需条件仍执行、使用错误来源或单位产生实质错误、维度不合法仍计算、条件已变却显示旧结果。合法的“无解”或“无实特征方向”按参考答案判定，不因结果非数值而视为失败。报告同时列出区域级与课件级计数，不将同一课件的许多区域当作大量独立材料。
